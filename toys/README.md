# Toys & Experiments

This page collects small tools, interactive demos, and experimental projects. The homepage navigation links to `/toys/`. Individual projects keep their own websites and repositories.

Each `article.toy-card` in `index.html` is one entry. Its title, short description, feature tags, and destination links describe the public project. The current collection begins with Opulse. A new article can be added inside `section.toys-collection` without changing the homepage or its navigation script.

The page is static HTML and works without JavaScript. `toys.css` contains the collection styles. `navigation.css` is shared with the homepage so the additional navigation link fits at intermediate screen widths. The base fonts, colors, header, and footer come from `../style-clean.css`.

The Opulse logo is served from its existing public website. Its title and links provide the project attribution. No private notes or unpublished research are part of this collection.
