任务T、表现P与经验E共同定义学习问题

5.1节第97页沿用Mitchell的定义框架。T说明系统要完成什么，P说明怎样衡量做得好，E说明程序可以观察什么。学习是改善任务能力的过程，任务本身可以是行走、分类或预测。一个系统在训练损失上的改进，只有与所选P和未来使用条件相联系时，才构成有意义的任务改善。

度量P必须表达目标行为

5.1.2第101至102页把准确率与错误率用于离散预测，把平均对数概率用于密度模型。准确率衡量正确样本比例，错误率对应平均0与1损失。对连续变量的密度值不能当作事件概率，也不适合用完全相等的命中率评价。

ℓ₀₁(ŷ,y)=1{ŷ≠y}; accuracy=1−error rate. Average log score=(1/m)Σᵢ log p_model(x⁽ⁱ⁾).

指标选择本身包含价值判断。序列完全正确率与逐字符正确率对不同错误结构敏感；平方损失比绝对损失更强调大误差。一个理想指标若计算不可行，还需要近似或替代标准。替代标准是否保留应用目标，属于额外论证，不由训练成功自动保证。

本笔记补充：训练目标、验证选择指标和最终报告指标可以不同，但这种差异必须显式说明。多次查看同一测试集会让它参与设计过程。即使每个模型都未直接拟合测试标签，整体选择仍可能对该测试样本产生适应。

从残差平方到正规方程

式5.6至5.12的推导只需要对参数求导。平方范数展开后，yᵀy与w无关，XᵀX对称，因此梯度为2Xᵀ(Xw−y)/m。本目标是凸二次函数，所以零梯度确实给全局最小值；这不是一般非凸损失的结论。

L(w)=‖Xw−y‖₂²/m=(wᵀXᵀXw−2wᵀXᵀy+yᵀy)/m.
∇L(w)=(2/m)Xᵀ(Xw−y); ∇²L(w)=(2/m)XᵀX ⪰0; XᵀXw=Xᵀy.
rank(X)=n ⇒ w*=(XᵀX)⁻¹Xᵀy. [5.12, with rank condition]

式5.12隐含X列满秩，因而m≥n且XᵀX正定。m≥n本身并不足够，重复列仍会使矩阵奇异。秩不足时仍有最小二乘解，但参数不唯一；伪逆给最小欧氏范数解，所有解的训练预测相同。

w*=X⁺y+v, v∈ker(X); Xw*=XX⁺y; Xᵀ(Xw*−y)=0.

本笔记补充数值边界：显式写逆用于说明解，不要求实现中真的求逆。正规方程会把满列秩X的二范数条件数平方。QR或SVD可以直接处理最小二乘，并保留更清晰的秩信息。它们不因此自动改善统计泛化。

经验风险、总体风险与泛化间隙

5.2第108至109页把泛化定义为对未见输入的表现，并在共同数据分布p_data下讨论训练与测试。用独立同分布样本可以把有限样本平均与总体期望联系起来。独立性和相同分布是不同要求；重叠样本、时间相关性或部署分布变化都需要额外处理。后面的风险记号是本笔记对来源叙述的形式化。

R(h)=E_(X,Y)∼p_data[ℓ(h(X),Y)]; R̂_S(h)=(1/m)Σᵢℓ(h(xᵢ),yᵢ); gap=R(ĥ_S)−R̂_S(ĥ_S).
R̂_train(w)=‖X_train w−y_train‖₂²/m_train; R̂_test(w)=‖X_test w−y_test‖₂²/m_test. [5.14 and following text]

固定且不依赖训练样本的h，在相同采样机制下有E[R̂_train(h)]=E[R̂_test(h)]=R(h)。学习后的ĥ_S依赖S，因此对训练样本的条件分布已不同。若测试集在选择之后仍独立，条件期望E[R̂_test(ĥ_S)|S]=R(ĥ_S)成立。一次有限测试均值仍有抽样误差。

来源说学习后预期测试误差不小于训练误差。本笔记保留其经验风险最小化语境：在固定假设空间中精确最小化经验风险时，下式成立。它不是任意算法或每次随机划分的保证，正则化解也未必是未惩罚训练误差的最小化者。

ĥ_S∈argmin_(h∈H)R̂_S(h) ⇒ E_S R̂_S(ĥ_S) ≤ inf_(h∈H)R(h) ≤ E_S R(ĥ_S).

理由是每个S上经验最小值都不大于任一固定h的经验风险，取期望后再取h的下确界即可。总体风险则总不小于同一空间的最优风险。这个论证同时说明了“先固定模型再采样”和“先采样再选模型”为何不同。

精确经验风险最小化是充分条件，并非必要条件。若在同一固定函数族上精确最小化经验风险加固定、数据无关的惩罚，对独立训练样本交换比较并取期望时，惩罚项相消，同样可得到预期训练误差不高于预期总体误差。上面的夹逼式只针对未惩罚ERM，不直接套用于惩罚解。

欠拟合、过拟合与容量的三个层次

第109至112页提出两个目标：降低训练误差，以及控制泛化间隙。欠拟合指训练误差仍不足够低；过拟合指训练与新样本之间差距过大。单看训练误差低不够，单看间隙小也不够，因为一个常数预测器可能在两边都表现很差。

Section 5.2, pp. 108 to 109, defines generalization through unseen inputs and discusses training and testing under a shared p_data. Independent identically distributed examples connect finite sample averages with population expectations. Independence and a common distribution are separate requirements. Overlapping examples, temporal dependence and a changed deployment distribution require additional treatment. The risk notation below formalizes the source discussion.

For h fixed independently of the training sample, the same sampling mechanism gives E[R̂_train(h)]=E[R̂_test(h)]=R(h). A learned ĥ_S depends on S, changing the relationship to its training examples. The source describes expected test error as at least expected training error after learning. This note retains the empirical risk minimization context. The inequality below holds for exact empirical risk minimization in a fixed hypothesis space. It is not a guarantee for every algorithm or every random split. A regularized solution need not minimize the unpenalized training error.

ĥ_S∈argmin_(h∈H)R̂_S(h) ⇒ E_S R̂_S(ĥ_S) ≤ inf_(h∈H)R(h) ≤ E_S R(ĥ_S).

For each S, the empirical minimum is no greater than the empirical risk of any fixed h. Taking expectation and then the infimum over h proves the first inequality. Exact empirical risk minimization is sufficient rather than necessary. Exact minimization of empirical risk plus a fixed, data independent penalty over the same fixed family also gives expected training error no greater than expected population error. Comparing solutions from independent training samples and taking expectations cancels the penalty terms. VC dimension, finite sample guarantees and their limits

Page 112 defines the VC dimension of a binary classifier through an existence statement. It is the largest m for which some set of m distinct inputs admits every binary labeling within the family. Every labeling must be realizable, but the point set need only exist. Every possible point set need not be shattered. VC dimension describes a function family rather than one fitted prediction vector.

The source gives a qualitative relationship. Higher capacity loosens bounds between training and population error, while more examples tighten them. It also notes that deep model bounds can be loose and that capacity and optimization restrictions are difficult to characterize. The following finite family bound is added note analysis. It shows explicitly how probability, loss range and sample count enter a guarantee. It is not an additional numbered theorem from the book.

For finite H, i.i.d. S, 0≤ℓ≤1 and 0<δ<1: Pr{sup_(h∈H)|R(h)−R̂_S(h)|≤√[log(2|H|/δ)/(2m)]}≥1−δ.

A bounded variable concentration bound for each fixed h, followed by a union bound over finite H, gives a simultaneous statement for the whole family. Its simultaneous nature permits later selection of h using S. An infinite family requires another complexity argument. Substituting an infinite |H| does not produce a useful bound. Unbounded squared loss also falls outside this statement.

Bayes error depends on both information and loss

Page 114 considers an ideal predictor that knows the true data distribution. Error can remain when the target is stochastic given the observed input or relevant variables are omitted. Bayes error is the optimal population risk for the available information and loss. It is not a lower bound on the error of each finite training sample.

Squared loss: f*(x)=E[Y|X=x]; R(f)=E[Var(Y|X)]+E[(f(X)−E[Y|X])²]; R*=E[Var(Y|X)].
Classification with 0/1 loss: h*(x)∈argmax_c p(c|x); R*=E_X[1−max_c p(c|X)].

The squared loss decomposition assumes finite second moments. The conditional residual Y−E[Y|X] has zero expected cross term with any input measurable function, separating conditional variance from prediction deviation. Classification instead chooses a category with maximal posterior probability. Different losses therefore produce different optimal predictions and different Bayes errors.

More data cannot restore input information that was never recorded. Training error below Bayes error is also consistent because a learner can memorize random training labels. A fixed family with insufficient capacity can retain approximation error above Bayes risk even with many examples.

Learning curves combine source evidence with idealized reasoning

The source trend explains why small samples can be fitted unusually well. More data make the fitting problem harder while improving population estimation. The quadratic model eventually remains above the noise floor, while the appropriately selected family approaches it. The preferred capacity can also change with sample size.

The p. 114 statement that expected generalization error cannot increase with more examples needs an idealized interpretation. An optimal decision procedure with extra observations can ignore them, so the best attainable risk cannot worsen merely because information increased. An arbitrary fixed algorithm has no universal monotone learning curve. Optimization changes, instability and selection can produce local increases. Convergence of a nonparametric method to Bayes risk also requires consistency and distribution conditions. The name alone does not provide them.

No Free Lunch depends on the averaging scheme

Section 5.2.1, pp. 114 to 116, uses No Free Lunch to examine universal generalization. Under an unweighted task average with no preferred structure, no classifier dominates on unseen inputs. The source emphasizes that an algorithm can still be better on a structured family of real problems. Learnability requires assumptions or preferences about the generating process.

An added finite case makes the averaging explicit. The input set is finite, and the average is uniform over every binary labeling function. After observing labels at seen points, the label at each unseen point remains an independent fair bit. Any predictor using only training information therefore has expected error 1/2 there. A prior favoring smoothness or local correlation changes the crucial condition.

This does not say that every algorithm behaves identically on every dataset or that model selection is meaningless. It asks which structure makes the chosen preference reasonable. Linear functions suit approximately linear relationships. A distance metric suits a task when nearby inputs should have similar outputs. Those judgments can fail, which makes independent validation necessary.

Regularization expresses preferences between functions

Section 5.2.2, pp. 116 to 118, broadens capacity control. Restricting a hypothesis space excludes some functions completely. A soft regularizer keeps them eligible but requires better fitting to offset the penalty. The source adds a squared weight norm to training MSE as weight decay. Regularization aims to improve generalization. It does not guarantee success on every problem or require a reduction in training error.

The following derivation extends 5.18 using the convention that every coordinate of w is penalized. MSE includes 1/m, so the linear system contains mλI. A convention using summed squared residuals gives a different numerical penalty strength for the same symbol λ.

∇J_λ=(2/m)Xᵀ(Xw−y)+2λw=0 ⇒ (XᵀX+mλI)w=Xᵀy.
λ>0 ⇒ w_λ=(XᵀX+mλI)⁻¹Xᵀy; for thin SVD X=UΣVᵀ: w_λ=V diag(σⱼ/(σⱼ²+mλ))Uᵀy.

For λ>0 the solution is unique even when X is rank deficient. Compared with the pseudoinverse factor 1/σⱼ, the spectral factor suppresses amplification along small singular value directions. This reduces sensitivity to some perturbations while introducing bias. A lower future risk still depends on the distribution and λ. As λ approaches 0, the fully penalized solution approaches the minimum norm least squares solution.

With an unpenalized b, centering X and y using training means permits fitting penalized slopes and recovering b=ȳ−wᵀx̄. Means and feature scales are estimated from the current training subset and then applied to validation and test examples. Parameters and hyperparameters depend on the learning level

Section 5.3, pp. 118 to 119, treats polynomial degree and weight decay strength λ as hyperparameters. They are set outside the current inner learning rule, while that rule fits w. Training, validation and testing serve different roles

Page 119 splits the original training pool into a fitting subset and a validation set while keeping the final test set separate. Its 80% and 20% split is a typical example, rather than an optimal ratio for every data size. Validation data participate in hyperparameter selection, making the selected validation error optimistic. The independent test set estimates generalization after all choices are complete.

The note adds a distinction about the splitting unit. It must match the intended object of generalization. Repeated measurements of one subject, near duplicate images or adjacent windows from a time series can make random row splitting exaggerate independence. Grouped and chronological splits address different estimation questions. They cannot simultaneously claim arbitrary random i.i.d. guarantees.

Normalization, feature selection and any estimated preprocessing are part of learning and are fitted within the current training split. Once hyperparameters are fixed, a prespecified rule can refit final parameters on the entire development pool. This changes the fitting sample size. The test set still evaluates the resulting final procedure.

The source also notes that years of repeated comparison can make a public benchmark optimistic. The issue concerns the accumulated use of test feedback throughout research. It is broader than whether one code path directly reads test labels. Fresh data, a genuinely separate evaluation or limited feedback can change the evidence conditions. An old test score alone cannot establish that selection bias has disappeared.
