核心问题与证据范围

输出的误差怎样决定隐藏层学什么

这篇短文讨论的不是怎样给输出单元指定答案，而是没有隐藏层标签时，网络怎样形成对任务有用的内部表示。输入和目标输出给定，隐藏单元应当表示什么却没有预先指定。论文把这个问题写成可微网络中的权重优化，并用反向传播把输出误差的导数传回内部连接。

笔记解释：反向传播计算梯度，梯度下降或动量规则才使用梯度更新参数。把两者分开很重要。同一条反向传播链可以服务于不同优化器；训练能否成功还取决于目标、参数化、初始化和更新尺度。本文使用 sigmoid 单元与平方误差，不能把今天常见的 softmax、交叉熵或随机小批量训练自动放回原文。

记号、前向计算与目标

连接的下标与偏置

原文的w_ji表示从单元i指向单元j的权重。x_j是单元j收到的总输入，y_j是其输出；这与某些教材把x用于外部输入向量的习惯不同。下文用a表示外部输入，保留原文的x、y与w下标方向。输出层记为O，样本索引为c。

x_j = Σ_i w_ji y_i; y_j = σ(x_j) = 1 / (1 + exp(−x_j)); σ′(x_j) = y_j(1 − y_j)

偏置可以并入一条恒为1的输入连接：y_0=1、w_j0=b_j。其梯度与普通权重使用同一条规则，只是乘上的输入恒为1。原文把偏置解释为符号相反的阈值。因此，负偏置要求正的连接输入来抵消它，不意味着该单元的输出严格为零。

E_c = (1/2) Σ_(j∈O) (y_j,c − d_j,c)²; E = Σ_c E_c

公式(3)把每个样本、每个输出的差异汇总成一个标量。隐藏层虽然没有目标状态，但每条内部连接都通过前向路径影响这个标量。学习需要的是这种间接影响的导数，而不是为隐藏单元补造一个正确答案。家谱任务还允许多个输出同时正确，因此目标不必是互斥的单类别。

原文分层网络允许连接跳过中间层，但不允许同层连接或从高层返回低层。前向状态依照层的先后顺序计算，同层单元可以并行。反向遍历则依赖相反的顺序。笔记解释：关键要求是计算依赖无环，而不是所有连接都必须只跨相邻两层。

链式法则与隐藏层信用分配

输出误差先变成局部输入的导数

对一个样本暂时省略c。原文公式(4)先得到∂E_c/∂y_j=y_j−d_j。再乘 sigmoid 的导数，便得到输出单元总输入的导数。δ_j不是目标减预测的误差残差，而是预测减目标之后再乘局部导数；混用这两种符号会把下降方向反过来。

j ∈ O: ∂E_c/∂y_j = y_j − d_j; δ_j = ∂E_c/∂x_j = (y_j − d_j)y_j(1 − y_j)

每条前向边对应一项反向贡献

∂E_c/∂w_ji = δ_j y_i; contribution through i → j: ∂E_c/∂y_i = δ_j w_ji

权重的梯度是接收单元的δ与发送单元激活的乘积。这个局部乘积只有在δ已经包含所有下游路径的影响时才完整。若单元i影响多个后继，∂E_c/∂y_i必须把各条路径的贡献相加，不能只选择最强或最近的一条连接。

∂E_c/∂y_i = Σ_(j∈succ(i)) w_ji δ_j; δ_i = y_i(1 − y_i) Σ_(j∈succ(i)) w_ji δ_j

这就是公式(7)与公式(5)在隐藏层的组合。先有后继的δ，再求当前单元的δ。每个中间导数计算一次并重复使用，避免为每一条权重各自重新展开整个函数。跨层连接也进入同一个后继求和，因此相同逻辑适用于原文允许的跳层网络。

从一个样本到论文使用的整轮更新

G_ji = ∂E/∂w_ji = Σ_c δ_j,c y_i,c; Δw_ji(t) = −εG_ji(t) + αΔw_ji(t − 1); w_ji(t + 1) = w_ji(t) + Δw_ji(t)

原文也提到每个样本后更新的替代方案，但这里报告的研究在所有训练样本上累积梯度后才改变权重。公式(8)是不带动量的下降；公式(9)加入前一轮的权重改变量。t随完整扫描一遍样本集而增加，ε是步长，α在0与1之间。这里的α不是新的误差导数，而是旧更新在当前更新中的保留系数。

笔记解释：如果把梯度总和改为平均值，步长也需要相应调整才能得到同样的更新。固定ε而改变训练集大小，会改变这里的更新尺度。动量可以平滑方向一致的多轮梯度，却不会保证单调降低误差，也不会把非凸优化变成全局收敛算法。

这个例子暴露的三个常见错误

第一，δ_h需要乘下游权重w；只把输出残差复制到隐藏层会漏掉路径敏感度。第二，隐藏层也需要自己的h(1−h)，不能重复使用输出层的y(1−y)。第三，先更新w再用新w计算δ_h，会把不同参数点的导数混在同一次步骤中。正确反向计算应当对应同一个前向状态。

Finite difference check: ∂E/∂θ ≈ [E(θ + q) − E(θ − q)] / (2q)

可检验的建议：对这个小网络用中心差分核对每个参数，并对多个q检查舍入误差与截断误差的平衡。对含多条下游路径的网络，再比较逐路径展开与反向累加。这里提出检验方法，没有声称这些扩展测试已经运行。

Note idealization: r = Σ_(k=1)^3 2^(k−1)(a_k − a_(7−k)); h₊ = σ(βr + b); h₋ = σ(−βr + b), b < 0

怎样理解分布式与泛化

人名在输入中各有一个独立单元，网络没有直接获得“第几代”或“哪个分支”的标签。图4显示同一隐藏特征可服务于多个同构位置的人。笔记解释：这种共享编码能让一个家族中的关系约束帮助另一个家族；它不等于自动恢复了唯一、符号化且因果正确的家谱规则。隐藏表示还可以在置换单元后保持相同函数。

保留4个三元组的证据有限。原文没有逐一列出保留列表、随机划分重复次数、置信区间或与记忆基线的系统比较。100个三元组也不能不加说明地解释成100个不同的人名加关系输入，因为一个输入可能对应多个正确输出。这个小实验支持关系结构可进入表示，不能单独估计对新家族、全新人名或新关系的表现。

更新选择、成本与可复现缺口

随机初始化、动量与衰减做不同的事

小的随机初值用于打破隐藏单元的对称性。如果同一层的两个单元拥有完全相同的入边、偏置和出边，它们会产生相同状态与导数，确定性更新可能始终保持这种重复。随机性因此提供不同的起点，但不直接提供任何家谱或对称性知识。

动量保留更新的历史，衰减直接缩小参数。图4中0.2%的衰减是家谱实验为便于解释权重而加入的做法，不是公式(9)中α的另一种写法。按“在每次改变后再缩小”的字面实现，下面给出一种算术表达；原文没有完整伪代码来消除所有实现先后顺序的细节。

Literal decay ordering for interpretation: w_new = (1 − 0.002)(w_old + Δw) = 0.998(w_old + Δw)

笔记解释：权重小不一定代表特征不重要。单位之间的重参数化、共同变化和输入尺度都会改变幅度的含义。原文用衰减后的幅度解释这一解的结构，是有帮助的定性线索，但不等同于现代因果重要性或经校准的特征归因。

反向传播的成本来自边与存储的状态

Derived scaling: one case forward + backward = O(M + U); P cases per full sweep = O(P(M + U)); sequential case storage ≈ O(M + U)

上式是笔记推导。M表示参与计算的连接数，U表示单元数，P表示训练样本数。每条边在前向与反向中只需常数级局部运算。每个单元的激活与局部导数还需逐个计算，这对应复杂度中的U项。全批量更新不要求同时保留所有样本的激活：可逐样本计算并把梯度累积在M个槽位中。若一次性保存全部样本状态，激活存储会达到O(PU)。这些是渐近估计，不是论文测得的时间或能耗。

循环网络、展开与共享参数

把时间变成前向计算的另一条轴

图5把同步循环网络运行三次的过程画成一个分层网络。每个时间步对应展开图的一层，同一循环连接在不同时间步出现为多个副本。这样可以用同样的前向与反向计算规则处理有限长度的迭代，而不是要求原始循环图本身满足无环条件。

Note notation for an unfolded state: y^(t+1) = σ(Wy^(t) + b), t = 0, …, T − 1

论文指出两个额外条件。反向计算需要之前各时间步的输出状态，因此需要保存状态历史。其次，对应时间步的权重必须保持相同，否则展开图训练出来的就是每一步各用一套参数的分层网络，不能映射回原来的固定循环网络。

The question and the evidence

How output error shapes a hidden representation

The central question concerns the hidden units. Training provides inputs and desired outputs, but it does not provide a label for each internal feature. The paper shows how an output objective can nevertheless shape those features. A backward computation assigns derivatives to internal connections, so changes to a hidden representation can be evaluated through their effect on the task.

Note interpretation: backpropagation computes a gradient. Gradient descent and momentum use that gradient to update parameters. This distinction separates derivative correctness from optimization success. The same derivative calculation can support different update rules, while the objective, parameterization, initialization and step size still affect learning. The source uses sigmoid units and squared error. Modern softmax, cross entropy and random minibatches are not assumed here.

Notation, the forward pass and the objective

Connection indices and biases

The source writes w_ji for a connection from unit i to unit j. The symbol x_j denotes a unit’s total input, while y_j denotes its output. This differs from notation that reserves x for the external input vector. Here a denotes an external input, O denotes the output layer and c indexes training cases. The original weight orientation is retained.

x_j = Σ_i w_ji y_i; y_j = σ(x_j) = 1 / (1 + exp(−x_j)); σ′(x_j) = y_j(1 − y_j)

A constant input y_0 = 1 makes its connection weight w_j0 the bias b_j. The same derivative rule then applies to biases because the incoming activation equals one. The paper describes a bias as a threshold with the opposite sign. A negative bias therefore requires positive incoming evidence to offset it. It does not make a sigmoid output exactly zero.

Why the objective reaches internal units

E_c = (1/2) Σ_(j∈O) (y_j,c − d_j,c)²; E = Σ_c E_c

Equation (3) combines errors across cases and output units into one scalar. An internal connection influences that scalar through forward paths even though no desired hidden state is specified. Learning therefore needs the derivative of this indirect influence rather than an invented target for a hidden unit. The family task also allows multiple correct outputs, so the target need not be an exclusive class label.

The layered network can have connections that skip intermediate layers. It excludes connections within a layer and connections from higher layers to lower ones. Forward states follow dependency order, and units in a layer can be evaluated in parallel. The backward computation follows the reverse order. The essential condition is an acyclic dependency structure rather than a requirement that every edge connect adjacent layers.

The chain rule and hidden unit credit

Output error becomes a derivative of total input

For one case, the case index can be suppressed. Equation (4) gives the output derivative y_j − d_j. Multiplication by the sigmoid derivative gives the derivative with respect to total input. With the convention used here, delta is a gradient rather than a desired minus predicted residual. Confusing these definitions reverses the sign of the parameter update.

j ∈ O: ∂E_c/∂y_j = y_j − d_j; δ_j = ∂E_c/∂x_j = (y_j − d_j)y_j(1 − y_j)

Each forward edge contributes to the backward derivative

∂E_c/∂w_ji = δ_j y_i; contribution through i → j: ∂E_c/∂y_i = δ_j w_ji

A weight derivative is the receiving unit’s delta multiplied by the sending unit’s activation. This local product is complete only after delta has accumulated all downstream effects. If unit i influences several successors, its activation derivative sums their contributions. Selecting only the largest contribution or only one nearby connection would omit valid paths.

∂E_c/∂y_i = Σ_(j∈succ(i)) w_ji δ_j; δ_i = y_i(1 − y_i) Σ_(j∈succ(i)) w_ji δ_j

The hidden recurrence combines equations (7) and (5). Successor deltas are available before the current delta is evaluated. Intermediate derivatives are computed once and reused. This avoids expanding the entire network function separately for every weight. A connection that skips a layer contributes to the same successor sum, so the rule also covers the skip connections permitted in the source.

From one case to the full sweep used in the paper

G_ji = ∂E/∂w_ji = Σ_c δ_j,c y_i,c; Δw_ji(t) = −εG_ji(t) + αΔw_ji(t − 1); w_ji(t + 1) = w_ji(t) + Δw_ji(t)

The source mentions an alternative that updates after each case. The reported research instead accumulates derivatives across all training cases before changing the weights. Equation (8) is gradient descent without momentum. Equation (9) retains part of the previous weight change. Time t advances after a complete sweep through the case set. Epsilon controls the current gradient contribution, while alpha retains part of the previous update. The momentum factor α lies between 0 and 1 in the source definition.

Note interpretation: replacing a gradient sum with a mean changes the update scale unless the learning rate changes accordingly. With fixed epsilon, a different number of cases can therefore change the effective step. Momentum can preserve a direction shared by successive gradients. It does not guarantee that every step lowers error or that a nonconvex objective reaches its global minimum.

Three errors exposed by the example

The hidden delta needs the downstream weight w. Copying an output residual to the hidden layer omits this sensitivity. The hidden delta also needs its own factor h(1 − h), rather than the output factor y(1 − y). Finally, updating w before computing the hidden delta mixes derivatives from different parameter points. A consistent backward pass corresponds to one stored forward state.

Proposed checks include a central finite difference for every parameter of this small network. Several values of q would reveal the balance between rounding and truncation error. A network with several downstream paths would also allow comparison between explicit path expansion and reverse accumulation. These are proposed checks, and no execution of those additional tests is claimed.

The caption interprets reflected weights within a hidden unit as equal in magnitude and opposite in sign. The three weights on one side follow a 1:2:4 relation. Note idealization: r = Σ_(k=1)^3 2^(k−1)(a_k − a_(7−k)); h₊ = σ(βr + b); h₋ = σ(−βr + b), b < 0

This formula is an idealized explanation of the mechanism, with beta setting its scale. It does not replace the printed learned values. When r is zero, both hidden units have similarly low activity. Sigmoid units remain continuous, so on and off describe activity ranges rather than exact Boolean states.

Independent counting gives 2⁶ = 64 inputs. A symmetric input is determined by its first three bits, so there are 2³ = 8 symmetric and 56 nonsymmetric patterns. The caption’s sweep definition gives 1,425 × 64 = 91,200 input presentations. These are arithmetic consequences of the setup. They are not additional accuracy measurements, variance estimates or hardware timings. The paper does not report a success distribution across random initializations.

What distributed representation and generalization mean here

Each person begins as a separate input unit. The network is not given generation or branch labels. Figure 4 shows a hidden feature serving people in corresponding structural positions. A shared code can let relational constraints from one family help the other. This interpretation does not imply recovery of a unique symbolic or causal rule for kinship. Permuting hidden units can also preserve the same network function.

The evidence from four withheld triples is limited. The article does not list the exact withheld set, repeated random splits, confidence intervals or a systematic memorization baseline. The 100 triples also do not establish 100 distinct person plus relation inputs because one input can have several correct outputs. The example supports representation of relational structure. It does not estimate performance on new families, entirely new people or unseen relationships.

Update choices, cost and reproduction gaps

Initialization, momentum and decay have different roles

Small random initial weights break symmetry between hidden units. Two units with identical incoming weights, biases and outgoing weights have identical states and derivatives. Deterministic updates can preserve that duplication. Randomness supplies different starting points, but it does not directly provide knowledge about family relations or mirror symmetry.

Momentum retains update history, whereas decay shrinks parameters. The family experiment introduces 0.2% decay to make weight magnitudes easier to interpret. This is different from the momentum coefficient alpha in equation (9). The following arithmetic expresses a literal shrinkage after the weight change. The paper does not provide full pseudocode that resolves every implementation detail.

Literal decay ordering for interpretation: w_new = (1 − 0.002)(w_old + Δw) = 0.998(w_old + Δw)

Note interpretation: a small weight does not necessarily identify an unimportant feature. Reparameterization, interactions and input scales can change how magnitude relates to function. The source uses decayed magnitudes to interpret this learned solution. That is a useful qualitative clue rather than a calibrated or causal feature attribution method.

Cost follows connections and stored states

Derived scaling: one case forward + backward = O(M + U); P cases per full sweep = O(P(M + U)); sequential case storage ≈ O(M + U)

These scalings are derived for this note. M is the number of computed connections, U the number of units and P the number of training cases. Each edge participates in a constant amount of local forward and backward work. Computing each unit’s activation and derivative adds the U term. A full batch update does not require storing activations for all cases at once. Cases can be evaluated sequentially while gradients accumulate in M storage locations. Retaining all case states at once instead gives O(PU) activation storage. These are asymptotic estimates rather than measured time or energy.

Recurrent unfolding and shared parameters

Time becomes another dependency axis

Figure 5 represents three iterations of a synchronous recurrent network as a layered network. Each time step becomes a layer in the unfolded computation. A recurrent connection appears as several copies at different times. The same forward and backward rules can then operate on a finite computation. The original recurrent graph itself need not be acyclic.

Note notation for an unfolded state: y^(t+1) = σ(Wy^(t) + b), t = 0, …, T − 1

The caption identifies two extra conditions. Backward computation needs the states from earlier time steps, so a state history is required. Corresponding connections must also keep the same value. Without that constraint, training would produce a layered network with a different parameter set at each step rather than the fixed recurrent network being represented.

The source average and the derivative of a shared parameter

Shared parameter chain rule: ∂E/∂w_shared = Σ_(t=1)^T ∂E/∂w^(t); source Figure 5 update uses ḡ = (1/T)Σ_(t=1)^T ∂E/∂w^(t)

Figure 5 explicitly averages derivatives across corresponding copies and applies that average to each copy. By the chain rule, the derivative of one shared variable is the sum of contributions from all its uses. If every shared parameter has T copies, averaging instead of summing is equivalent to reducing the learning rate by T. If copy counts differ between parameters, separate averages are no longer one uniform learning rate change.

Derived recurrent scaling: forward + backward over T steps = O(T(M + U)); stored state history = O(TU)

These time and memory expressions are again derived here, assuming M connections and U state values per step. The source suggests applications to iterative search and sequential structure. This short article does not give separate numerical experiments for those tasks, long dependency curves or a truncated backward procedure. Figure 5 therefore does not establish successful learning over long sequences.

Limits, relationships and questions for further tests

A correct gradient does not guarantee optimization or generalization

The source discusses local minima and acknowledges that gradient descent need not find a global minimum. The authors report that poor outcomes were uncommon in their experience and suggest that extra connections can provide routes around obstacles. This is an empirical observation from their tasks. It is not a convergence theorem for arbitrary widths, data distributions or random seeds.

The derivative exposes another limitation. A sigmoid near zero or one has a small factor y(1 − y). Products of sensitivities along several layers can become small, depending on both weight scales and activation states. The article does not quantify this behavior through a modern depth study. It is identified here as a risk visible in the equations rather than a completed source ablation.

Tests that could separate mechanism from an isolated success

One proposed study would repeat random initializations for the symmetry task. It would record convergence frequency, sweep counts and output margins, then compare one, two and more hidden units. This could test how typical the illustrated solution is and whether extra capacity mainly changes optimization. No such runs were generated or executed for this note.

A second proposed study would publish every family training input, its complete target vector and the withheld facts. Random fact withholding could then be compared with withholding a person or an entire family. Controlled removal of decay, momentum or the tolerance would identify their separate effects. These splits ask different generalization questions. One result on four facts cannot substitute for all of them.

A third proposed study would check the summed shared gradient for a finite recurrent computation. Figure 5’s averaging rule could be compared after the corresponding learning rate conversion. Changing the unfolding length would then expose state storage and gradient magnitude. This separates correct parameter tying, comparable update scale and the difficulty of optimizing long paths.

The causal chain worth retaining

A differentiable forward computation connects weights to task error. The chain rule transfers output sensitivities to hidden states. Local products then give connection derivatives. Joint updates can make internal features reflect useful task structure. The symmetry and family examples demonstrate organized hidden features through this chain. Their boundaries remain equally important: no global optimization guarantee, no large scale generalization estimate and no validated biological learning mechanism.
