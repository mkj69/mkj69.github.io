将减法移到前向计算内部

ICML 官方页面确认论文正式标题为 Beyond Logits: Coherent Hallucination Mitigation via Attention Contrastive Decoding。

本笔记使用 PMLR 306 的正式论文集 PDF，它链接至同一 OpenReview 记录。

方法比较干净输入与诱发幻觉输入的注意力模式，而不是减去最终词表 logit。

其预期优势是让后续网络将干预转化为连贯的输出分布。

自适应减法

令 A_c、A_n 表示干净输入与扰动输入在同一对齐位置上的注意力权重。

均匀对比会使用 (1 + α)A_c − αA_n。

自适应策略只在噪声权重大于干净权重的位置减去噪声项。

M_i = 1{A_n,i > A_c,i}; A_ACD = (1 + α)A_c − α(A_n ⊙ M)

当 M_i 为零时，干净权重直接放大，不含减法项。

当 M_i 为一时，更新会压低被扰动增强的注意力分量。

随后，value 通过这一修改后的注意力在解码器中聚合。

展示的算术可能产生负分量，且不必和为一。

因此，不应将修改后的权重展示为普通概率分布，或视作有保证的语义证据。

论文的平滑性动机是关于干预位置的假设，而不是连贯性保留的证明。

X + ACD 的实际含义

第 4.1 节说明，X + ACD 保留 X 构造诱发幻觉分支的方法，但替换其 logit 减法和合理性筛选。

不应未经核对就将它实现为两个独立对比修正的叠加。

与 ICD 结合时，需要匹配提示词长度，以对齐注意力位置。

默认设置将该操作应用于解码器各层与各注意力头。

Move the subtraction inside the forward pass

The official ICML page identifies this paper as Beyond Logits: Coherent Hallucination Mitigation via Attention Contrastive Decoding.

This note uses the PMLR 306 proceedings PDF, linked to the same OpenReview record.

The method compares clean and hallucination-inducing attention patterns rather than subtracting the final vocabulary logits.

The intended benefit is to let the remaining network transform the intervention into a coherent output distribution.

1 / 5PMLR 306, 2026, pp. 16704–16741

Adaptive subtraction

Let A_c and A_n be attention weights for clean and perturbed inputs at the same aligned positions.

A uniform contrast would use (1 + α)A_c − αA_n.

The adaptive strategy subtracts the noisy weight only where it exceeds the clean weight.

M_i = 1{A_n,i > A_c,i}; A_ACD = (1 + α)A_c − α(A_n ⊙ M)

When M_i is zero, the clean weight is amplified without the subtraction term.

When M_i is one, the update suppresses an attention component increased by the perturbation.

The values then aggregate through this modified attention within the decoder.

The displayed arithmetic can produce negative entries and need not sum to one.

Consequently the modified weights must not be presented as an ordinary probability distribution or as guaranteed semantic evidence.

The paper's smoothness motivation is a hypothesis about the intervention location, not a proof of preserved coherence.

What X + ACD means

Section 4.1 states that X + ACD retains X's hallucination-inducing construction but replaces its logit subtraction and plausibility filter.

It should not be implemented as an unexamined stacking of two independent contrastive corrections.

ICD integration requires matching prompt lengths to align attention positions.

The default applies the operation across decoder layers and heads.

Evidence and limitations

On LLaVA-1.5 in Table 1, VCD's instance-level CHAIR decreases from 16.2 to 14.3 with ACD, while recall increases from 76.8 to 78.3.

For SID the corresponding figures are 14.1 to 13.3 and 78.2 to 79.4.

These are benchmark-specific percentages, not guarantees for arbitrary images or reasoning tasks.

The evaluation includes Qwen-VL, POPE, MME, and judge-based LLaVA-Bench comparisons.

A useful reproduction should compare against the same sampling and candidate-filter settings and report malformed outputs separately from hallucinations.

Noise-induced attention changes are proxies; high attention on a location does not alone establish that the associated content is false.
