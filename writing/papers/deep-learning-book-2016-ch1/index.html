本次范围与核心问题

表示、计算与证据之间的关系

本次单元仅覆盖本书第1章 Introduction，印刷页1至26。第1.1节介绍读者与全书结构，第1.2节及其四个小节提供历史背景。后续章节尚未覆盖，这不是全书笔记。

原章用表示和组合解释深度学习。下面不逐段重述教材，而是围绕一个可检验的问题展开独立分析：同样的数据与预测目标，为什么改变内部坐标、函数分解或参数共享方式，会改变学习和执行的难度。公式、反例与小型算术表均为笔记推导，除非明确标注为原章数据。

组合何时带来新的表达能力

线性层的数量本身不够

独立推导：若每层只是仿射变换，任意多层仍能合并成一次仿射变换。增加这些层的数量会改变参数化和优化，但不会自动得到新的输入到输出函数类。这个反例让“深度”与“非线性”各自承担明确作用。

h₁=W₁x+b₁; h₂=W₂h₁+b₂ ⇒ h₂=(W₂W₁)x+(W₂b₁+b₂).

一个可逐点核对的非线性构造

独立例子用布尔异或说明中间计算的作用。输入只取0或1，令s=x₁+x₂。两个ReLU中间量再线性组合，就能在这四个输入上精确得到异或。这里给出的是存在性构造，不是训练结果。

s=x₁+x₂; h₁=max(0,s); h₂=max(0,s−1); f(x)=h₁−2h₂, for x∈{0,1}².

单个仿射阈值若把(0,0)和(1,1)判为0，却把另外两点判为1，会要求b<0、w₁+b>0、w₂+b>0、w₁+w₂+b<0。中间两个不等式相加得到w₁+w₂+2b>0，与其余条件矛盾。非线性中间量改变了可实现边界，然而这个证明仍未说明随机初始化和某个优化器会找到上面的解。

这个例子也没有证明任意增加层数都会有效。函数分解需要和问题结构配合。多余的层可以只实现恒等变换；一个过窄的中间层则可能先丢掉必要信息。表达能力、参数效率与可学习性需要分别论证。

深度的度量与共享计算

深度依赖允许的基本操作

Same function: f(x)=σ(wᵀx). Scalar multiply → sum → sigmoid: depth 3. Logistic-regression primitive: depth 1. Source: Figure 1.3.

独立解释：比较两个架构的深度之前，需要固定允许的基本操作，以及是否把求和视为一个操作。如果把一次高维归约展开为二元加法树，路径长度又会变化。不能只给更强的基本操作取一个名称，就据此宣称实际计算变少。

参数共享与执行次数是两个轴

独立构造考虑同一个状态变换重复T次，激活ρ是固定的逐元素函数。展开后存在T次函数应用，但只需要保存一份可训练参数。给每一步独立参数会扩大模型类，却不改变相同展开长度下的函数应用次数。下面只核算W与b，假设状态维度固定且变换稠密，不计固定初始状态h₀和任何额外输出头。

h_(t+1)=ρ(Wh_t+b), t=0,…,T−1; h_t∈ℝᵈ; fixed elementwise ρ. W,b only: shared d²+d; unshared T(d²+d). Dense forward work O(Td²).

如果训练需要通过全部T次使用求导，直接保存各步状态需要O(Td)的激活空间，参数存储仍是O(d²)。这些是一般计算图的推导，不是第1章测得的内存数据。额外的分支、注意力或更高维状态会改变成本，不能被这个简化表达式涵盖。

“模型中的概念层数”和“为了推断这些概念而进行的迭代次数”也不等价。一个浅的关系图可以反复交换信息，得到较长的计算路径。因此，一个完整架构描述至少需要说明表示结构、展开计算与共享约束。

组合表示的容量与歧义

可组合的编码不等于已经学会组合

下面的独立编码例子与原章对分布式表示的讨论有关，但采用不同的数值。假定物体有4种形状和5种颜色，并且所有组合都有效。为每个组合分配一个独立指示量需要20个槽位。分别编码形状与颜色只需9个槽位，仍能表示20个组合。

Independent coding arithmetic: joint one-hot width = ab; factorized one-hot width = a+b. For a=4, b=5: ab=20 and a+b=9.
独立构造的编码容量比较，不是神经元计数实验或压缩率测量。
表示宽度可表示组合数需要的条件
联合指示2020每种组合有自己的槽位
因子指示920形状与颜色的组合约束可由解码器处理

节省编码槽位只说明一种表示存在。它没有说明从图像恢复这些槽位是否容易，也没有说明预测器会在未见组合上正确工作。如果训练集只出现红色圆形和蓝色方形，颜色与形状可能一直共变，多个内部解释会同样符合训练数据。

内部坐标通常不唯一

If y=g(φ(x)) and A is invertible, then φ′(x)=Aφ(x), g′(z)=g(A⁻¹z) ⇒ g′(φ′(x))=g(φ(x)).

上式是独立的重参数化论证，前提是表示和读出函数类容许Aφ与g∘A⁻¹。受约束的架构不一定容许任意可逆混合。在这个前提下，即使输出预测完全相同，隐藏坐标仍可改变。因此，某个隐藏单元与颜色相关，不足以证明模型找到了唯一的颜色因子，更不足以建立因果含义。稀疏、独立或可解释等额外要求需要独立定义和证据。

一个针对组合泛化的检验可以留出某些形状与颜色配对，同时让每一种单独属性在训练中出现。随机留出图片与留出整个配对检验不同能力。这样的设计只是笔记提出的问题，没有在本次阅读中运行。

学习目标、成本与历史数字

表示学习仍需要目标与数据分布

Note formalization: f_(θ,ψ)(x)=g_ψ(φ_θ(x)); R̂(θ,ψ)=(1/N)Σ_i ℓ(f_(θ,ψ)(x_i),y_i); R_P(θ,ψ)=E_(x,y)∼P[ℓ(f_(θ,ψ)(x),y)].

这些符号是笔记的形式化，不是第1章编号公式。θ控制表示，ψ控制读出，N表示训练样本数。降低训练平均损失R̂不自动保证目标分布P上的风险R_P降低。若训练图像的背景稳定地指示标签，表示可以利用背景捷径，却在背景改变后失效。

重建目标也有类似边界。一个自编码器可以把输入完整编码后再解码，却不把下游任务需要的变量组织成简单读出形式。把重建误差、类别分离和对干扰因素的稳定性分开测量，才可能知道哪种“好表示”得到了改善。

Note reconstruction objective: min_(θ,ψ) (1/N)Σ_i ||x_i−d_ψ(φ_θ(x_i))||². Small reconstruction loss alone does not imply a simple predictor of y.

训练成本与样本数不能分开理解

Note accounting: C_eval ≈ Σ_(l=1)^L d_(l−1)d_l for dense affine layers; parameter count = Σ_(l=1)^L[d_(l−1)d_l+d_l]; one epoch forward work ≈ N·C_eval.

这个核算忽略激活函数的低阶成本、数据读取、通信和反向计算常数。它说明增加样本数会增加一次全数据扫描的工作量，却没有给出达到某个误差所需的扫描次数。模型、优化器、批量、硬件利用率与数据分布共同决定实际时间，不能仅由参数数目推算GPU时长。

阅读后可明确回答的问题

为什么改变表示能帮助简单模型？因为目标边界在新坐标中可以更简单，如本笔记的径向分类。为什么这不保证所有任务受益？因为表示可能合并对新目标有区别的输入。为什么深度不能脱离基本操作比较？因为同一函数可以按不同粒度展开。为什么紧凑编码不保证组合泛化？因为训练数据可能没有区分所假设的因子。

Scope and the central question

Representation, computation and evidence

This unit covers Chapter 1, Introduction, printed pages 1 to 26. Section 1.1 describes the audience and book structure. Section 1.2 and its four subsections provide historical context. Later chapters are not covered. This is not a whole-book reading note.

The chapter motivates deep learning through representation and composition. This note develops a separate analytical question: why do coordinates, function decomposition and parameter sharing change the difficulty of learning and execution for the same prediction task? Equations, counterexamples and small arithmetic tables are note derivations unless identified as chapter data.

Three separate judgments

Independent analytical table. These forms of evidence are not interchangeable.
JudgmentEvidence that can support itGuarantee still missing
ExpressivityA parameter setting represents the targetTraining can find it

A useful representation can make a simple predictor effective. It can also discard information needed for the target. A deeper decomposition supplies intermediate computation, while adding optimization and storage costs. The existence of helpful features therefore does not establish a universal benefit from greater depth.

How coordinates change separability

The question raised by the source figure

An independent example uses 8 points. The inner class occupies the four axis directions at radius 1. The outer class occupies the same directions at radius 2. This explicit construction permits a proof without treating the source image as a dataset.

Note construction: A = {(1,0), (−1,0), (0,1), (0,−1)}; B = {(2,0), (−2,0), (0,2), (0,−2)}; y(A)=1, y(B)=0.

If an affine score wᵀx+b is positive on the inner class and negative on the outer class, its class averages impose contradictory conditions. Averaging the four scores within either class cancels the coordinates and leaves b. The inner class requires b>0, while the outer class requires b<0. A single strict linear threshold in the original coordinates is therefore insufficient.

When composition changes expressivity

Counting linear layers is insufficient

Independent derivation: a stack of affine maps collapses into a single affine map. Extra layers change parameterization and optimization, but do not automatically enlarge the class of functions from inputs to outputs. This counterexample gives depth and nonlinearity separate roles.

h₁=W₁x+b₁; h₂=W₂h₁+b₂ ⇒ h₂=(W₂W₁)x+(W₂b₁+b₂).

A nonlinear construction with an exact truth table

An independent Boolean XOR example shows the role of intermediate computation. Inputs take only 0 or 1, and s=x₁+x₂. Two ReLU intermediate values followed by a linear combination produce the exact output on these four inputs. This is an existence construction, not a training result.

s=x₁+x₂; h₁=max(0,s); h₂=max(0,s−1); f(x)=h₁−2h₂, for x∈{0,1}².

A single affine threshold that rejects (0,0) and (1,1) while accepting the other points requires b<0, w₁+b>0, w₂+b>0 and w₁+w₂+b<0. Adding the middle inequalities gives w₁+w₂+2b>0, which contradicts the remaining conditions. Nonlinear intermediates change the realizable boundary. The proof does not show that a particular optimizer and initialization will find this solution.

The example does not establish that arbitrary extra layers help. A decomposition needs to match task structure. Redundant layers can implement an identity map, while a narrow intermediate state can lose necessary information. Expressivity, parameter efficiency and learnability require separate arguments.

Depth conventions and shared computation

Depth depends on the primitive operations

Same function: f(x)=σ(wᵀx). Scalar multiply → sum → sigmoid: depth 3. Logistic-regression primitive: depth 1. Source: Figure 1.3.

Independent interpretation: a depth comparison needs a fixed primitive set and a convention for reductions. Expanding a high-dimensional sum into binary additions changes path length again. Naming a stronger primitive does not by itself reduce the work needed to execute it.

Parameter sharing and execution count are separate axes

An independent construction repeats the same state transition T times with a fixed elementwise activation ρ. Its unfolded computation contains T function applications, but only one trainable parameter set. Giving each step independent parameters enlarges the model class without changing the number of applications at the same unfolded length. The accounting counts W and b only. It assumes a dense transition of fixed width and excludes a fixed initial state h₀ and any extra output head.

h_(t+1)=ρ(Wh_t+b), t=0,…,T−1; h_t∈ℝᵈ; fixed elementwise ρ. W,b only: shared d²+d; unshared T(d²+d). Dense forward work O(Td²).

Differentiating through all T uses with direct state storage requires O(Td) activation space, while shared parameter storage remains O(d²). These are general graph calculations, not memory measurements in Chapter 1. Branches, attention and changing state widths require different accounting.

The number of conceptual levels also differs from the number of inference iterations. A shallow relational graph can exchange information repeatedly and produce a long computation path. A complete architecture description therefore needs its representational structure, unfolded computation and sharing constraints.

Combinatorial reuse and ambiguity

A compositional code does not guarantee compositional learning

The following independent coding example relates to the chapter’s discussion of distributed representation, but uses different numbers. An object has 4 shapes and 5 colors, with all combinations valid. A separate indicator for each combination needs 20 slots. Separate shape and color indicators need 9 slots and still represent 20 combinations.

The slot reduction establishes that a representation exists. It does not show that images can be mapped to those slots easily or that a predictor will handle unseen combinations. If training contains only red circles and blue squares, color and shape co-vary. Several internal explanations can fit the same training observations.

Internal coordinates are often nonunique

If y=g(φ(x)) and A is invertible, then φ′(x)=Aφ(x), g′(z)=g(A⁻¹z) ⇒ g′(φ′(x))=g(φ(x)).

This independent reparameterization argument assumes that the representation and readout families admit Aφ and g∘A⁻¹. A constrained architecture need not admit every invertible mixing. Under this assumption, hidden coordinates can change while predictions remain identical. A hidden unit correlated with color therefore does not establish a unique color factor or a causal interpretation. Sparsity, independence and interpretability need separate definitions and evidence.

A possible compositional test withholds selected shape and color pairs while exposing each individual attribute during training. Random image holdout and complete pair holdout test different capabilities. This design is a question proposed by the note. No such experiment was run.

Learning objectives, cost and historical numbers

Representation learning still needs an objective and a distribution

Note formalization: f_(θ,ψ)(x)=g_ψ(φ_θ(x)); R̂(θ,ψ)=(1/N)Σ_i ℓ(f_(θ,ψ)(x_i),y_i); R_P(θ,ψ)=E_(x,y)∼P[ℓ(f_(θ,ψ)(x),y)].

This notation is the note’s formalization, not a numbered equation from Chapter 1. Parameters θ control the representation, ψ control the readout, and N is the training set size. A lower empirical loss R̂ does not guarantee lower risk R_P on the target distribution P. Stable correlations between backgrounds and labels can support a shortcut that fails after the background changes.

Reconstruction has a similar boundary. An autoencoder can retain an input without organizing variables relevant to the task for a simple readout. Separate measurements of reconstruction, class separation and stability to nuisance changes are needed to identify which sense of a good representation improved.

Note reconstruction objective: min_(θ,ψ) (1/N)Σ_i ||x_i−d_ψ(φ_θ(x_i))||². Small reconstruction loss alone does not imply a simple predictor of y.

Training cost and sample count interact

Note accounting: C_eval ≈ Σ_(l=1)^L d_(l−1)d_l for dense affine layers; parameter count = Σ_(l=1)^L[d_(l−1)d_l+d_l]; one epoch forward work ≈ N·C_eval.

This accounting omits activation costs, data loading, communication and backward-pass constants. More examples increase the work of one full data pass, but do not determine how many passes reach a target error. Model structure, optimizer, batch size, hardware utilization and data distribution jointly affect elapsed time. Parameter count alone does not determine GPU hours.
