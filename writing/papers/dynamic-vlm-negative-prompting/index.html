由正在生成的图像决定负提示

VL-DNP 在生成期间改变负提示内容，而不只是改变数值强度。

在选定去噪步骤，模型预测干净图像，并请视觉语言模型描述可见的不希望元素。

这一描述成为后续步骤的负提示，直至下一次查询。

不应悄悄将空描述或无关描述视为可靠的安全证据。

从潜变量状态到干预

对保持方差的扩散，干净图像估计使用当前潜变量与预测分数。

x̂₀ = [x_t + (1 − ᾱ_t)s_CFG(x_t,t)] / √ᾱ_t; c⁻_i = VLM(x̂₀,D)

后续修正将正向引导与负概念方向结合。

式 5 从条件分数出发，而式 2 从无条件分数出发。

因而在相同符号下，两者的正向引导系数相差一；复现必须核对实现约定。

随时间变化的提示还会在采样中改变目标，因此该程序不是从一个固定倾斜分布进行精确采样。

实验设置

论文将 Stable Diffusion v1.4 与 Qwen2.5-VL-7B-Instruct 配合，使用 50 步 DPM-Solver++。

十个 VLM 查询索引为 45、44、43、41、38、34、29、23、16 和 8。

安全测试使用 Ring-a-Bell-16、P4D 与 Unlearn-Diff；正常内容评估仅有 100 个 COCO 提示词。

负引导强度为 15 时，P4D ASR 对动态方法为 0.225，对静态负提示为 0.053。

动态方法更好保留 CLIP，为 0.311 对 0.296，因此结果是权衡，而非过滤始终更强。

所报告单图时间为动态提示 29.673 秒、静态提示 11.967 秒、基础模型 8.0 秒。

用表格核对 Pareto 主张

正文声称动态提示支配全部静态点和 SAFREE。

但动态点的 CLIP 最高为 0.312，低于强度 7.5 的静态点 0.313，以及 SAFREE 的 0.315。

因而报告数值不能证明在所展示安全与 CLIP 坐标上存在字面意义的 Pareto 支配。

同样，动态强度从 20 增至 25 时，Ring-a-Bell ASR 从 0.011 升至 0.032，因此提升并非严格单调。

应保留这些差异，而不是在总结中将它们改写成更强主张。

局限

早期干净图像预测可能模糊，VLM 可能遗漏内容或虚构负向描述。

正常样本较少使 FID 比较不稳定，应进一步进行更大规模的重复评估。

复现应记录每个中间图像、返回的负提示、引导权重和 VLM 延迟。

Let the emerging image choose the negative prompt

VL-DNP changes the content of the negative prompt during generation, not only its numerical strength.

At selected denoising steps, the model predicts a clean image and asks a vision-language model to describe unwanted visible elements.

That description becomes the negative prompt for subsequent steps until the next query.

An empty or irrelevant description should not be silently treated as reliable evidence of safety.

1 / 62510.26052v1

From latent state to intervention

For variance-preserving diffusion, the clean-image estimate uses the current latent and predicted score.

x̂₀ = [x_t + (1 − ᾱ_t)s_CFG(x_t,t)] / √ᾱ_t; c⁻_i = VLM(x̂₀,D)

The subsequent correction combines positive guidance with a negative-concept direction.

Equation 5 starts from the conditional score, whereas Equation 2 starts from the unconditional score.

Consequently their positive-guidance coefficients differ by one under the same symbol; reproductions must verify the implemented convention.

A time-varying prompt also changes the target during sampling, so the procedure is not exact sampling from one fixed tilted distribution.

Experimental setting

The paper pairs Stable Diffusion v1.4 with Qwen2.5-VL-7B-Instruct and uses 50 DPM-Solver++ steps.

The ten VLM query indices are 45, 44, 43, 41, 38, 34, 29, 23, 16, and 8.

Safety tests use Ring-a-Bell-16, P4D, and Unlearn-Diff; benign evaluation contains only 100 COCO prompts.

At negative scale 15, P4D ASR is 0.225 for the dynamic method and 0.053 for static negative prompting.

The dynamic method preserves CLIP better, at 0.311 versus 0.296, so the result is a tradeoff rather than uniformly stronger filtering.

Reported per-image time is 29.673 seconds for dynamic prompting versus 11.967 for static prompting and 8.0 for the base.

Check the Pareto claim against the table

The text claims that dynamic prompting dominates all static points and SAFREE.

But the dynamic points have CLIP at most 0.312, below static 0.313 at scale 7.5 and SAFREE 0.315.

The reported values therefore do not establish literal Pareto dominance on the displayed safety-CLIP axes.

Likewise the Ring-a-Bell ASR rises from 0.011 to 0.032 between dynamic scales 20 and 25, so improvement is not strictly monotone.

These discrepancies should stay visible rather than being converted into stronger claims in a summary.

4 / 62510.26052v1

Limitations

Early clean-image predictions can be blurry, and the VLM can miss content or hallucinate a negative description.

The small benign sample makes FID comparisons fragile and should motivate larger repeated evaluations.

A reproduction should log every intermediate image, returned negative prompt, guidance weight, and VLM latency.
