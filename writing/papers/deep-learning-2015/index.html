问题：究竟把什么变成可学习的？

核心变化

综述连接了表征学习、卷积模型与循环模型。本笔记关注这条联系如何改变学习系统的设计。

Prediction = gθ(φψ(x)); both θ and ψ can receive gradients from the objective.

特征映射 φ 将输入变成表征，预测器 g 再利用它。特征映射固定时，优化只能改变预测器。两者都可训练时，误差还可以改变系统向预测器暴露哪些信息。这既改变参数数量，也改变搜索空间。

深度需要发挥具体作用

aᴸ = fᴸ(Wᴸ fᴸ⁻¹(Wᴸ⁻¹ ⋯ f¹(W¹x + b¹) ⋯ + bᴸ⁻¹) + bᴸ)

函数复合让后续计算可以利用中间结果。但深度本身不保证得到有用表征。如果所有激活都是线性的，多层仿射映射仍可合成一个仿射映射。非线性阶段改变了表达能力，数据、架构与优化仍决定最终学到什么函数。

论证的检查路径

分析先从局部导数走到完整参数更新，再讨论空间共享、分布式编码与时间共享，最后区分数学容量和经验证据。下面的推导与小型计算是独立编写的解释，教学数值会明确标注。

历史语境

逐层无监督预训练在 2006 年前后帮助重新激起了研究兴趣。2012 年 ImageNet 结果推动深度卷积模型获得关注。作者预期无监督学习、选择性注意与推理会变得更重要。这些判断属于 2015 年，提供了这里的问题背景，不能直接确定当前表现。

反向传播：先得到导数，再更新参数

先固定局部计算的含义

y = q(x); z = r(y); dz/dx = (dz/dy)(dy/dx)

x 的小变化先改变 y，y 的变化再改变 z，因此两次局部敏感度相乘。中间变量分别作为前一步的输出与后一步的输入。如果把第一个因子替换成 dz/dx，就会重复计入 x 到 y 的敏感度，不再表示这次复合。

向量形式

a⁰ = x; zˡ = Wˡaˡ⁻¹ + bˡ; aˡ = fˡ(zˡ); E = ½‖aᴸ − y‖²

目标为 y，上标 l 表示层。在这里的推导中，激活函数逐元素作用。令 δ 表示 E 对 z 的导数，就得到下面的递推。

δᴸ = (aᴸ − y) ⊙ fᴸ′(zᴸ)
δˡ = ((Wˡ⁺¹)ᵀδˡ⁺¹) ⊙ fˡ′(zˡ)
∂E/∂Wˡ = δˡ(aˡ⁻¹)ᵀ; ∂E/∂bˡ = δˡ

转置矩阵把下游敏感度传回对它有贡献的输入，逐元素乘积计入局部激活函数，外积再得到与权重同形状的矩阵。偏置以加法进入预激活，因此偏置梯度不需要再与激活做外积。

小批量梯度对选中的样本取平均。均匀采样时，它估计数据集平均目标的梯度，不同批次会给这个估计带来波动。目标、采样方式与学习率仍然重要。测量泛化需要使用拟合数据之外的样本。

卷积：局部性、共享与信息损失

结构先验

卷积层在数组不同位置重复使用局部规则。当同一种局部模式可能在不同位置出现时，这种结构就有用。但它也排除了每个位置都需要独立参数的一些函数。因此，共享是一种关于有效结构的假设，并不是无代价地增加灵活性。

N_conv = kₕk𝑤C_inC_out + C_out; N_dense = (HWC_in)D + D
独立教学例子的参数计数。
教学层假设可训练参数
卷积3 × 3 核；C_in = 3；C_out = 16448
全连接32 × 32 × 3 输入；D = 1649,168

输出形状与表达能力不同。这里仅分析参数共享，不构成准确率或速度的受控比较。

参数量与计算量不同

MACs_conv ≈ H_outW_outkₕk𝑤C_inC_out

共享权重可以在许多空间位置重复使用，因此参数较少也可能对应很大的计算量。上式的乘加次数近似没有计入偏置、激活与访存。实际延迟还取决于数据布局、批量、实现和硬件利用率。

感受野通过复合扩大

r₀ = 1; j₀ = 1; r_l = r_(l−1) + (k_l − 1)j_(l−1); j_l = s_lj_(l−1)

对没有空洞的普通一维堆叠，r 是感受野大小，j 是相邻感受野中心在输入坐标中的间距。两个核大小为三、步幅为一的层，得到大小为五的感受野。二维时可分别对两个坐标轴计算。填充会改变边界位置看到的数值。

等变性与不变性不同

Φ(Tx) = TΦ(x) versus Ψ(Tx) = Ψ(x)

第一式保留了变换发生的位置关系，第二式让输出忽略这种变化。定位往往需要前者，类别标签可能对某些变换需要后者。严格的平移性质取决于边界、采样与步幅，池化并不能由此保证任意旋转或视角的不变性。

分布式编码：容量并不等于保证

组合数量

n binary coordinates admit 2ⁿ distinct configurations.

一个坐标可以参与许多不同配置，因此表征能够紧凑地表达组合。数量说明有多少编码可用，却没有确定一个未见编码应当对应什么标签。泛化还需要目标函数和学习器具有额外结构。

独立构造的歧义：两种规则都拟合已观测行。
输入加法规则 f另一规则 g教学例子中是否观测
(0, 0)00是
(0, 1)11是
(1, 0)11是
(1, 1)2100否

加法假设会选择一种从观测延伸的方式，查表规则则可以选择另一种。前三个输入上的完全一致无法区分它们。这个小例子把缺失的假设直接展示出来，更大的编码空间本身不能消除这种歧义。

嵌入通过它的用途获得含义

e_i = E onehot(i); logits_i = We_i

从 E 中选出的列是输入符号的向量，下游计算再将它变成预测。因此，它的用途与预测问题及训练分布有关，单个分量未必对应一个人类概念。

E′ = AE; W′ = WA⁻¹; W′E′ = WE for invertible A

这个简单线性读出模型存在等价参数化。嵌入坐标经过可逆变换后，每个 logit 仍可不变，但某些变换会改变欧氏距离。因此，坐标与可视化需要结合模型解释。二维投影本身不能证明唯一的语义几何。

循环：跨时间共享参数

状态是一种重复计算

h_t = f(Wh_(t−1) + Ux_t + b); o_t = g(Vh_t + c)

某个时间步的状态取决于前一状态和当前输入。展开后，这些依赖成为普通计算图。图随序列长度增长，但参数仍然共享。不同状态副本不等于不同的可训练矩阵。

∂E/∂W = Σ_t δ_t h_(t−1)ᵀ, where δ_t = ∂E/∂z_t

W 的每次使用都会贡献给同一个参数梯度，因此需要对共享矩阵的使用位置求和。某个状态的总 δ 包含它对后续计算的影响。如果把展开后的矩阵分别学习，就定义了另一个模型。

时间上的归因为何困难

J_t = ∂h_t/∂h_(t−1) = diag(f′(z_t))W
∂h_T/∂h_t = J_TJ_(T−1) ⋯ J_(t+1)

早期敏感度需要穿过雅可比矩阵乘积。范数界可以说明缩小或增大的可能性，但方向与相互作用也重要。单一特征值的口号不足以刻画非线性时变系统。序列长度改变了远距离依赖需要经过的因子数量。

门控记忆路径

c_t = f_t ⊙ c_(t−1) + i_t ⊙ g_t
∂c_t/∂c_(t−1) along the direct memory edge = diag(f_t)

这个一般化门控单元具有直接的加法路径。遗忘门接近一时，该路径可以保留敏感度。但完整导数还包括经过门和隐藏状态的其他路径。这是一种传递信息的机制，并不能保证任意任务都能学到任意长的依赖。

编码与生成

p(y₁, …, y_T | x) = ∏_(t=1)^T p(y_t | y_<t, x)

编码器可以向解码器提供关于 x 的信息。这个分解将生成定义为逐步建立条件分布。训练可以使用真实的前序词元，生成则依赖自己此前的选择，两种上下文可能不同。输出流畅并不能单独证明输入的每个相关细节都被保留。

原文背景原文位置限定

数值要支持比较，首先需要测量协议。速度比需要基线、硬件、实现、精度、批量和停止条件。错误率需要数据划分与指标定义。缺少这些条件时，历史数值可以提供阅读背景，却不足以支持新的性能预测。

一个有用的成本分解

Training work ≈ updates × examples per update × work per example

这个分解区分了参数量无法替代的三个量。表征可能紧凑，激活却仍很大。共享权重可能被重复应用许多次。循环序列可能增加保存状态或重计算的需求。因此，内存、算术、通信和延迟需要分别核算。

优化判断需要假设

综述在讨论大型网络时，更强调鞍点而非较差局部极小值。这个判断的适用范围很重要。

非凸目标可以包含不同类型的驻点。梯度为零不能识别全局最小值，负曲率方向可以帮助区分鞍点和局部最小值。某些训练得到好解，也不能证明所有架构或初始化都有相同的损失地形。一般性保证需要先定义目标函数类别，再给出适用于该类别的论证。

表征只保留某些信息

预测目标奖励对该预测有用的信息，可能不会约束其他差别。因此，分类、定位、重建与生成可能偏好不同的中间表征。一个重要问题是：输入中的哪些变化应当改变输出？这把架构的不变性与具体任务联系起来。

无标签学习与行动学习

重建或预测目标可以在没有人工类别标签的情况下产生训练信号。这改变了监督信号的来源，却没有消除目标选择。会主动选择观测的智能体又引入一层依赖：行动影响后续能获得什么信息。因此，完整分析还要包含观测策略及其反馈，而不只是表征。

带答案的回顾问题

反向传播提供什么？它提供既定目标沿计算图的导数，不会替代目标、学习率或评估分布的选择。

参数共享为什么可能有帮助？它让多个观测共同约束同一条规则。好处取决于这条规则是否确实适合在这些观测之间共享。

为什么编码空间大还不够？它只计算可能表征的数量，没有规定未见组合上的目标函数。前面的歧义表给出了明确反例。

循环模型为什么能参数少而计算深？参数在每个时间步重复使用，展开后的依赖链仍随序列长度增长。

一个定性输出能证明什么？它展示该例子上的行为。估计可靠性需要明确样本与指标，解释机制则需要关于计算过程的额外证据。

The question: what becomes learnable?

The central change

The review connects representation learning with convolutional and recurrent models. The question for this note is how that connection changes the design of a learning system.

Prediction = gθ(φψ(x)); both θ and ψ can receive gradients from the objective.

A feature map φ turns an input into a representation. A predictor g then uses that representation. When the feature map is fixed, optimization can only change the predictor. When both are trainable, an error can change which information the system exposes to the predictor. This is a change in the search space, as well as a change in the number of parameters.

Depth needs a role

aᴸ = fᴸ(Wᴸ fᴸ⁻¹(Wᴸ⁻¹ ⋯ f¹(W¹x + b¹) ⋯ + bᴸ⁻¹) + bᴸ)

Composition lets an intermediate result be reused by a later computation. Depth alone does not ensure a useful representation. If every activation is linear, successive affine maps collapse into a single affine map. Nonlinear stages change that expressivity. Data, architecture and optimization still determine which function is learned.

How the argument will be examined

The analysis proceeds from a local derivative to a complete parameter update. It then considers spatial sharing, distributed codes and temporal sharing. The final sections separate mathematical capacity from empirical evidence. The derivations and small calculations below are original explanations. Constructed numbers are labelled explicitly.

The historical frame

Layerwise unsupervised pretraining helped renew interest around 2006. The 2012 ImageNet result made deep convolutional models prominent. The authors expected unsupervised learning, selective attention and reasoning to become more important. These are 2015 judgments. They motivate questions here rather than establish current performance.

Backpropagation: a derivative, then an update

A local calculation fixes the meaning

y = q(x); z = r(y); dz/dx = (dz/dy)(dy/dx)

A small change in x first changes y. That change in y then changes z. The two local sensitivities therefore multiply. The intermediate variable appears once as an output and once as an input. Replacing the first factor by dz/dx would repeat the x to y sensitivity and would no longer express this composition.

The vector form

a⁰ = x; zˡ = Wˡaˡ⁻¹ + bˡ; aˡ = fˡ(zˡ); E = ½‖aᴸ − y‖²

The target is y. The superscript l indexes layers. Each activation acts element by element in this derivation. Defining δ as the derivative of E with respect to z gives the following recurrence.

δᴸ = (aᴸ − y) ⊙ fᴸ′(zᴸ)
δˡ = ((Wˡ⁺¹)ᵀδˡ⁺¹) ⊙ fˡ′(zˡ)
∂E/∂Wˡ = δˡ(aˡ⁻¹)ᵀ; ∂E/∂bˡ = δˡ

The transpose routes downstream sensitivity back to the inputs that contributed to it. The elementwise product accounts for the local activation. The outer product then gives a matrix with the same shape as the weights. Bias gradients need no activation outer product because each bias enters its preactivation additively.

Backpropagation computes derivatives. An optimizer chooses how to use them. A correct derivative does not guarantee that a large step lowers the objective. A lower training objective also leaves a separate empirical question about performance on unseen data.

From a derivative to SGD

L_B(θ) = (1/|B|) Σ_(i∈B) ℓ_i(θ); θ_new = θ − η∇L_B(θ)

A minibatch gradient averages the selected examples. With uniform sampling, it estimates the gradient of the dataset mean. Different batches introduce variation into that estimate. The objective, sampling scheme and learning rate still matter. Measuring generalization requires examples outside the data used for fitting.

Convolution: locality, sharing and information loss

A structural prior

A convolutional layer reuses a local rule across an array. This is useful when the same local pattern can matter at different positions. It also excludes functions that need unrelated parameters at every position. Sharing is therefore an assumption about useful structure, rather than a free increase in flexibility.

N_conv = kₕk𝑤C_inC_out + C_out; N_dense = (HWC_in)D + D

Output shapes and expressivity differ. This calculation isolates parameter sharing. It is not a controlled accuracy or speed comparison.

Parameters and computation are different counts

MACs_conv ≈ H_outW_outkₕk𝑤C_inC_out

A shared weight can be used at many spatial locations. Fewer parameters can therefore coexist with substantial computation. The approximate multiply accumulate count above omits biases, activation work and memory traffic. Latency also depends on layout, batching, implementation and hardware utilization.

Receptive fields grow through composition

r₀ = 1; j₀ = 1; r_l = r_(l−1) + (k_l − 1)j_(l−1); j_l = s_lj_(l−1)

For an ordinary one dimensional stack without dilation, r is the receptive field size and j is the spacing between neighboring receptive field centers in input coordinates. Two kernels of size three with stride one give a receptive field of five. In two dimensions, the same calculation applies to each axis. Padding changes which boundary values are observed.

Equivariance differs from invariance

Φ(Tx) = TΦ(x) versus Ψ(Tx) = Ψ(x)

The first relation preserves where a transformation went. The second removes that change from the output. Localization often needs the first property. A category label may benefit from the second for selected transformations. Exact translation statements depend on boundaries, sampling and stride. Pooling does not establish invariance to arbitrary rotations or viewpoints.

Distributed codes: capacity is not a guarantee

A combinatorial count

n binary coordinates admit 2ⁿ distinct configurations.

A coordinate can participate in many different configurations. That gives a representation a compact way to express combinations. The count says how many codes are available. It does not identify the correct label for an unseen code. Generalization requires additional structure in the target function and in the learner.

An embedding is learned through its use

e_i = E onehot(i); logits_i = We_i

The column selected from E is a vector for an input symbol. A downstream computation converts it into a prediction. Its usefulness is therefore tied to the prediction problem and the training distribution. A component need not correspond to a single human concept.

E′ = AE; W′ = WA⁻¹; W′E′ = WE for invertible A

This simple linear readout has equivalent parameterizations. An invertible change of embedding coordinates can leave every logit unchanged. Some such changes alter Euclidean distances. Coordinates and plots therefore need interpretation in the context of the model. A two dimensional visualization alone cannot prove a unique semantic geometry.

Recurrence: shared parameters across time

A state is a repeated computation

h_t = f(Wh_(t−1) + Ux_t + b); o_t = g(Vh_t + c)

The state at a time step depends on the preceding state and the current input. Unrolling exposes these dependencies as an ordinary computation graph. The graph grows with sequence length. The parameter set remains shared. A separate copy of the state is a different object from a separate trainable matrix.

∂E/∂W = Σ_t δ_t h_(t−1)ᵀ, where δ_t = ∂E/∂z_t

Each use of W contributes to the same parameter gradient. The sum is over uses of a shared matrix. The total δ at a state includes its effects on later computations. Treating the unrolled matrices as independently learned would define a different model.

Why temporal credit can be difficult

J_t = ∂h_t/∂h_(t−1) = diag(f′(z_t))W
∂h_T/∂h_t = J_TJ_(T−1) ⋯ J_(t+1)

Early sensitivity passes through a product of Jacobians. Norm bounds can explain shrinking or growing sensitivity. Their directions and interactions also matter. A single eigenvalue slogan does not fully characterize a nonlinear time varying system. Sequence length changes the number of factors through which a distant dependency must pass.

A gated memory path

c_t = f_t ⊙ c_(t−1) + i_t ⊙ g_t
∂c_t/∂c_(t−1) along the direct memory edge = diag(f_t)

This generic gated cell has a direct additive path. A forget gate near one can preserve sensitivity along that path. The full derivative also includes paths through the gates and hidden states. This is a mechanism for carrying information, rather than a guarantee that a task will learn arbitrarily long dependencies.

Encoding and generation

p(y₁, …, y_T | x) = ∏_(t=1)^T p(y_t | y_<t, x)

An encoder can supply information about x to a decoder. The factorization defines generation one conditional distribution at a time. Training can condition on observed earlier tokens. Generation conditions on its own earlier choices. These contexts can differ. A fluent output does not by itself establish that every relevant input detail was retained.

A numerical claim needs a measurement protocol before it supports a comparison. A speed ratio needs a baseline, hardware, implementation, precision, batch size and stopping condition. An error rate needs a dataset split and metric definition. Without those conditions, a historical number can orient a reading without supporting a new performance prediction.

A useful cost decomposition

Training work ≈ updates × examples per update × work per example

This decomposition separates three quantities that a parameter count cannot replace. A representation may be compact while activations remain large. A shared weight can be applied many times. A recurrent sequence can increase stored state or recomputation. Memory, arithmetic, communication and latency therefore need separate accounting.

Optimization claims need assumptions

The review emphasizes saddle points over poor local minima in large networks. The scope of that argument matters.

A nonconvex objective can contain stationary points of different kinds. A zero gradient does not identify a global minimum. A negative curvature direction can help distinguish a saddle from a local minimum. The existence of good training solutions also does not prove that every architecture or initialization has the same landscape. A general guarantee requires a stated class of objectives and an argument for that class.

A representation preserves some information

A prediction objective rewards information useful for that prediction. It may leave other distinctions unconstrained. Classification, localization, reconstruction and generation can therefore favor different intermediate representations. A useful question is which changes in the input should alter the output. This connects architectural invariances to the actual task.

Learning without labels and learning to act

A reconstruction or prediction objective can obtain a training signal without a manually supplied category label. That changes where supervision comes from. It does not remove the choice of objective. An agent that selects observations adds another dependency: its actions affect which information becomes available. A complete analysis then includes the observation policy and its feedback, as well as the representation.

Optimization determines how that signal changes parameters. Generalization concerns behavior beyond the observations used for fitting. A clear reading keeps these roles connected without merging them.

A bibliographic correction

Reference 102 links to the wrong captioning paper. The matching Vinyals, Toshev, Bengio and Erhan paper is arXiv:1411.4555. The printed destination, arXiv:1502.03044, belongs to Xu and colleagues.

Questions with substantive answers

What does backpropagation supply? It supplies derivatives of a defined objective through a computation graph. It does not choose the objective, the learning rate or the evaluation distribution.

Why can parameter sharing help? It makes multiple observations constrain the same rule. The benefit depends on whether that rule should actually be shared across those observations.

Why is a large code space insufficient? It counts possible representations. It does not specify the target function on unseen combinations. The ambiguity table gives an explicit counterexample.

Why can a recurrent model have few parameters and a deep computation? Its parameters are reused at every step. The unrolled dependency chain still grows with sequence length.

What does a qualitative output establish? It shows behavior on that example. Estimating reliability needs a defined sample and metric. Explaining a mechanism requires additional evidence about the computation.
