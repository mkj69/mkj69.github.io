Decoding-Unlearning: Fact Forgetting via Entropy-Guided Inference

Original note, sentence-aligned / 原创笔记逐句对照。Not a full-paper translation / 不是论文全文翻译。

English / 中文 · Source / 原文

A probe chooses the decoding route

用探针选择解码路径

SEGUE performs inference-time fact suppression without updating model weights.

SEGUE 在不更新模型权重的情况下进行推理时事实抑制。

Its first component appends a decision probe to the query and reads the model's own output head to decide whether the query concerns a forget concept.

第一部分在查询后追加决策探针，并通过模型自身输出头判断查询是否涉及遗忘概念。

The probe's key/value cache is then discarded while the original query cache is retained.

随后丢弃探针的 key/value 缓存，同时保留原查询缓存。

This separates the control decision from subsequent answer generation, although both computations use the same model.

这将控制决策与后续回答生成分开，尽管两种计算使用同一个模型。

A decision error can still send a benign query to the forgetting route or a target query to the retaining route.

决策错误仍可能将正常查询送入遗忘路径，或将目标查询送入保留路径。

Entropy over input positions, not over next tokens

熵的对象是输入位置，而非下一词分布

For each candidate vocabulary token v, the method projects intermediate hidden states at the query positions through the output head.

对每个候选词表词元 v，方法将查询各位置的中间层隐藏状态投影到输出头。

Softmax over input positions produces a distribution of contribution scores for that candidate.

对输入位置做 softmax，得到该候选词元的贡献分数分布。

P̃(i|v,Q) = exp((Wh_i)_v) / Σ_j exp((Wh_j)_v); TTE(v,Q) = −Σ_i P̃(i|v,Q) log P̃(i|v,Q)

Low target-token entropy means that the candidate's projected support is concentrated at a few query positions.

较低的目标词元熵意味着，该候选词元的投影支持集中在少数查询位置。

The authors use this concentration as a proxy for entity-triggered factual recall.

作者将这种集中性作为实体触发事实回忆的代理信号。

This is not attention entropy, a causal attribution proof, or a guarantee that the candidate is true.

它不是注意力熵、因果归因证明，也不能保证候选词元为真。

Spurious sharp projections motivate combining entropy with the candidate logit.

偶然形成的尖锐投影，促使方法将熵与候选 logit 结合。

Hard masking and smooth suppression

硬掩码与平滑抑制

The retaining route scores tokens with l′_v = l_v − β TTE(v).

保留路径使用 l′_v = l_v − β TTE(v) 为词元打分。

The forgetting route identifies the top-k factual candidates under that adjusted score and assigns them negative infinity.

遗忘路径找出该调整分数最高的 k 个事实候选，并将其设为负无穷。

The remaining logits receive a nonlinear entropy-dependent bias.

剩余 logit 接收依赖熵的非线性偏置。

b_v = −(l_v/l_max)[1 − tanh(TTE(v))]; l′_v = l_v + α b_v, v ∉ V_fact

The entropy dictionary is computed on the initial query and reused during generation to reduce cost.

熵字典在初始查询上计算，并在生成过程中复用，以降低成本。

This relies on factual dependencies remaining useful as the response develops.

这依赖于回答发展过程中事实依赖仍具有参考价值。

The raw-logit ratio is not invariant to adding a constant to every logit, so implementation details matter here.

原始 logit 的比值不对整体加常数保持不变，因此这里的实现细节很重要。

Evidence and the interpretation of success

证据与成功的解释

Table 1 reports RWKU question-answer retention falling from 54.55 to 4.65 for Llama-2-7B, while general accuracy changes from 44.47 to 43.06.

表 1 中，Llama-2-7B 的 RWKU 问答保留指标从 54.55 降至 4.65，同时通用准确率从 44.47 变为 43.06。

The reported fluency changes from 4.01 to 3.98.

所报告流畅性从 4.01 变为 3.98。

MUSE News in Table 2 gives retention 4.79 and general accuracy 41.57, compared with 58.45 and 44.48 for the original model.

表 2 的 MUSE News 保留指标和通用准确率为 4.79、41.57，原模型为 58.45、44.48。

Lower factual recall is desirable for these forget metrics, but coherent invented answers should not be confused with factual reliability.

对这些遗忘指标，较低事实回忆是期望结果，但连贯的虚构答案不能与事实可靠性混为一谈。

WMDP results measure restricted benchmark knowledge, not proof that harmful capability is absent.

WMDP 结果衡量限定基准知识，不是有害能力已不存在的证明。

A reproduction should test routing errors, paraphrases, longer continuations, and retained facts alongside the reported fluency.

复现应在报告流畅性的同时，测试路由错误、改写提问、较长续写和保留事实。

The trained weights remain unchanged, so bypassing the decoding intervention remains outside its protection.

训练好的权重保持不变，因此绕过解码干预不在其保护范围内。
