问题：容量与结构如何同时成立

一个完整系统的结果

论文的问题是，大型卷积网络能否直接从带标签图像中学到有效的视觉表示。答案依赖多个环节共同成立。卷积限制假设空间，GPU 让更大的模型能够训练，ReLU 加快拟合，数据增强与 dropout 抑制过拟合。最终基准测量的是这个系统，不能把全部收益归于某一个因素。

本笔记以完整会议论文 PDF 为依据。PDF 摘要给出 top 1 错误率 37.5%、top 5 错误率 17.0% 与约 650,000 个神经元。会议网页摘要却列为 39.7%、18.9% 与 500,000 个神经元。两份记录不同，因此本笔记的分析与表格以完整 PDF 为准。常被引用的 15.3% 属于 ILSVRC 2012 竞赛集成模型，对应另一套评测设置。

指标对应明确的错误事件

err_top1 = (1/M) Σ_i 1[argmax_c pθ(c|x_i) ≠ y_i]; err_top5 = (1/M) Σ_i 1[y_i ∉ Top5(pθ(·|x_i))]

Top 5 错误率统计真实类别没有进入概率最高的五个标签的比例。它不是五次预测错误率的平均值，也不直接衡量定位、概率校准或鲁棒性。因此，竞赛错误率下降回答的是一个比通用视觉理解更窄的问题。

架构：先理解连接，再理解层数

网络包含五个卷积层与三个全连接层。归一化和池化增加计算步骤，但不增加这里统计的有权重层数。ReLU 提供隐藏层非线性，最终分类器通过 softmax 输出 1,000 类的概率分布。第 3.5 节给出连接方式，Figure 2 展示这些连接如何分布到两个设备上。

GPU 划分改变了计算图

第 2、4、5 层只读取同一 GPU 上的前层特征图，第 3 层则读取两路特征图。全连接层也连接完整的前层表示。因此，两路不是独立训练的分类器。受限连接同时减少部分层的通信与参数，它既是实现选择，也是架构本身的一部分。

原文尺寸不能完整确定 padding

H_out = floor((H_in + 2P − K)/S) + 1; floor((224 − 11)/4) + 1 = 54; 55 × 55 × 96 = 290,400

上式采用普通卷积、对称 padding 与无空洞卷积的假设。正文和 Figure 2 均写输入为 224 × 224 × 3，同时图中首层空间网格为 55 × 55。核大小 11、步长 4 时，不补边的 224 输入会产生 54 个位置。Padding 可以改变结果，但 PDF 未完整说明边界约定。直接把 224 改成 227 会改写原文记录。

Figure 2 图注列出的首层神经元数为 253,440，与图中 55 × 55 × 96 的乘积不一致。因此，摘要约 650,000 个神经元的说法在这里作为规模描述，而非已经核对一致的精确总和。后面的计算会明确列出尺寸假设。

参数共享的局部算子

z[o,u,v] = b[o] + Σ_(c∈G(o)) Σ_a Σ_b W[o,c,a,b] x[c,Su+a−P,Sv+b−P]

输入通道集合 G(o) 取决于输出所在的分组。空间位置变化会改变读取的输入区域，却不会选择另一套卷积核。正是这一点，使同一层可以拥有较少参数，同时把每个参数用于很多空间位置。

拟合速度与局部竞争

ReLU 改变局部导数

ReLU(z) = max(0,z); d ReLU(z)/dz = 1 for z > 0, and 0 for z < 0; d tanh(z)/dz = 1 − tanh²(z)

正输入区域的 ReLU 导数为一，tanh 接近饱和时导数很小。这一局部机制可以加快梯度拟合，但不能避免负输入 ReLU 的局部导数为零，也不能单独证明测试误差会改善。原文明确区分拟合速度与正则化效果。

响应归一化沿通道进行

bᵢ_(x,y) = aᵢ_(x,y) / (k + α Σ_(j=max(0,i−⌊n/2⌋))^(min(N−1,i+⌊n/2⌋)) (aʲ_(x,y))²)^β; k = 2; n = 5; α = 10⁻⁴; β = 0.75

这里的 a 是 ReLU 之后的激活。分母在同一空间位置累加相邻通道的响应，较大的邻近响应会压低归一化输出。通道顺序没有先验含义，但在训练前固定。原公式是 α 乘求和，没有再除以 n。若某个库采用 α/n 的定义，复现时需要相应换算参数。

该操作位于第 1、2 个卷积层之后，不减去局部均值。因此，它不同于先减均值的对比度归一化，也不同于跨 minibatch 的归一化。其作用需要结合这个架构中的实验来判断，不能据此推成所有 ReLU 网络的必要条件。

池化选择保留下来的局部响应

p[c,u,v] = max_(0≤a<3, 0≤b<3) h[c,2u+a,2v+b]

网络使用 3 × 3 窗口、步长 2，相邻窗口发生重叠。作者比较的是 2 × 2 窗口、步长 2，并在其设置中保持等价输出尺寸。报告的收益只对应这一比较。池化会丢弃部分精确位置信息，因此不能视作没有代价的不变性。

数据增强：不变性来自具体选择

预处理建立固定输入

先把图像短边缩放到 256 像素，再取中央 256 × 256 区域，并减去训练集像素均值。网络接收 RGB 值，而非手工设计的特征描述子。但这条流程仍然会在模型看到图像之前进行一次空间选择。

裁剪是不同观察，不是独立样本

训练时随机抽取 224 × 224 图块，并进行水平翻转。作者将可能训练视图的扩充描述为 2,048 倍。这些视图共享原始照片与标签，统计信息高度相关，不能解释为独立样本数也增加了 2,048 倍。

这项增强假定，适度平移与水平翻转通常保持类别不变。它是对当前数据集的近似。裁剪可能移走物体，某些任务中的变换也可能改变语义。因此，增强策略本身就定义了学习问题的一部分。

预测时平均十个概率分布

p̄(c|x) = (1/10) Σ_(t=1)^10 pθ(c|T_t(x))

测试视图由四个角与中央图块及其水平翻转组成。网络对十个图块的 softmax 概率取平均。这增加推理计算，但不是十套独立参数的模型集成，也不是先平均 logits 再做 softmax。

PCA 扰动作用于整张图像

ΔI = [p₁,p₂,p₃] [α₁λ₁, α₂λ₂, α₃λ₃]ᵀ; α_i ∼ Normal(0,0.1²); I′_(x,y) = I_(x,y) + ΔI

p 与 λ 分别来自训练集 RGB 像素协方差矩阵的特征向量和特征值。每次使用一张图像时，各 α 只采样一次，并由该图像的全部像素共享；下次使用该图像时重新采样。PDF 公式乘的是 λ，而不是 λ 的平方根。

这一低维扰动近似照明强度与颜色的变化。同一 RGB 偏移应用于所有位置，因此不同于逐像素独立噪声。第 4.1 节报告 top 1 错误率降低超过一个百分点。增强在 CPU 上生成，同时 GPU 处理前一批数据，因此在该实现中大部分成本与训练重叠。

优化与 dropout：具体改变了什么

目标函数提高正确标签的概率

pθ(c|x) = exp(z_c)/Σ_(j=1)^1000 exp(z_j); L_B(θ) = −(1/|B|) Σ_(i∈B) log pθ(y_i|x_i)

第 3.5 节最大化正确类别的平均对数概率，与最小化上式的负值等价。类别标签通过反向传播监督全部有权重层。但训练目标下降并不能单独证明保留集错误率下降，所以还需要正则化与评测细节。

原始 dropout 约定

m_j ∼ Bernoulli(0.5); h̃_j = m_j h_j during training; h̃_j = 0.5 h_j at test time

Dropout 用于前两个全连接层。每次输入采样一个掩码，不同掩码共享底层权重。被丢弃的激活既不贡献前向值，也不贡献这条局部反向路径。它削弱特征对某一组固定搭档的依赖，但不等于分别训练所有子网络。

测试时，原文保留全部单元，并把输出乘以 0.5。许多后来的实现改为训练时把保留激活除以保留概率，测试时不再缩放。混用两种约定会改变计算。原文将确定性测试缩放视作模型组合的近似，而不是整个非线性网络的精确等式。

作者报告，不使用 dropout 时网络有明显过拟合，使用后收敛所需迭代次数约翻倍。这是在当前设置中，用更多优化工作换取更好的泛化，不能与竞赛时对多个完整 CNN 的预测取平均混为一谈。

SGD 包含耦合的权重衰减

g_i = (1/|D_i|) Σ_(x,y∈D_i) ∂ℓ(x,y;w_i)/∂w; v_(i+1) = 0.9v_i − 0.0005εw_i − εg_i; w_(i+1) = w_i + v_(i+1)

每批包含 128 个样本，动量为 0.9，权重衰减为 0.0005。衰减项与学习率 ε 一同进入速度更新，这不是现代解耦权重衰减优化器的定义。作者还观察到，小幅衰减降低了训练误差，其作用不只是缩小训练与测试之间的差距。

其中约 96.2% 的参数位于全连接层，而大部分乘加计算发生在卷积层。因此，一层可以占用较少参数存储，却需要大量计算。卷积层即使参数占比很小，移除后也可能显著影响表现。

规模估计与实测不同

60,965,224 × 4 bytes ≈ 243.9 MB; 724,406,816 × 10 ≈ 7.244 × 10⁹ MACs per image; 90 × 1.2 × 10⁶ / 128 ≈ 843,750 updates

参数存储估计假设每个参数四字节，并采用十进制 MB。梯度、动量、激活与临时缓冲还会增加内存。十视图估计假定重复执行单图块计算、不共享计算；更新次数采用近似数据集大小与轮数。这些都不是实测延迟、完整显存预算或训练 FLOP 总量。

原文的实际硬件报告

第 5 节报告，在两块各 3 GB 的 NVIDIA GTX 580 上训练约五至六天，约等于一次训练运行消耗十至十二个 GPU day。它不等于架构选择、失败运行、预训练与集成的全部研究成本。原文的计时信息不足以重建这些总量，也不足以精确给出每个竞赛方案的推理成本。

主要约束是相互耦合的。更大网络需要更多存储与时间，正则化也可能增加迭代次数。第二块 GPU 可能使另一种模型成为可行方案，而不只是让相同模型跑得更快。因此，清晰的速度比较需要先固定模型与停止标准。

The problem: enough capacity, enough structure

A result produced by a system

The paper asks whether a large convolutional network can learn useful visual representations directly from labelled images. Its answer depends on several parts working together. Convolution limits the hypothesis space. GPUs make a larger model trainable. ReLUs make fitting faster. Augmentation and dropout limit overfitting. The benchmark result measures this combined system. It does not isolate one universal cause.

The full conference PDF is the source for this note. Its abstract reports 37.5% top 1 error, 17.0% top 5 error and about 650,000 neurons. The proceedings landing page instead lists 39.7%, 18.9% and 500,000 neurons. These records differ, so the complete PDF governs the analysis and tables here. The often quoted 15.3% result belongs to the ILSVRC 2012 competition ensemble. It is a different evaluation setting.

A large collection does not remove the need for assumptions. The authors motivate convolution through local pixel dependencies and approximately stationary image statistics. A filter can reuse one local feature at many positions. This reduces the number of unrelated decisions that learning must infer from the finite dataset. It does not make object recognition invariant to every viewpoint or background.

A metric is a precise event

err_top1 = (1/M) Σ_i 1[argmax_c pθ(c|x_i) ≠ y_i]; err_top5 = (1/M) Σ_i 1[y_i ∉ Top5(pθ(·|x_i))]

Top 5 error asks whether the correct class is absent from the five highest ranked labels. It is not the mean error across five predictions. The metric also does not measure localization, calibration or robustness. A lower competition error therefore answers a narrower question than general visual understanding.

The complete nine page PDF was read, including its notes and references. All four source figures were visually checked. This note reproduces the architecture and activation plots because they support direct technical discussion. It does not independently reread every cited work or establish the reader’s completion of any reading pass.

The architecture: connectivity before a layer list

Eight learned layers

The network contains five convolutional layers and three fully connected layers. Normalization and pooling add operations but not additional learned weight layers in this count. ReLUs supply hidden nonlinearities. The final classifier produces a distribution over 1,000 classes through softmax. A GPU split changes the graph

Layers 2, 4 and 5 only see the preceding maps on their own GPU. Layer 3 sees both groups. Fully connected layers also connect across the preceding representation. The two streams therefore exchange information, rather than train as independent classifiers. Restricted connections reduce communication and parameters at selected layers. They are part of the architecture as well as its implementation.

The printed shapes do not fully specify padding

H_out = floor((H_in + 2P − K)/S) + 1; floor((224 − 11)/4) + 1 = 54; 55 × 55 × 96 = 290,400

This ordinary convolution shape rule assumes symmetric padding and no dilation. The text and Figure 2 label the input as 224 × 224 × 3. The figure also labels the first convolutional grid as 55 × 55. With a kernel of 11 and stride of 4, an unpadded input of 224 produces 54 positions. Padding can change the result, but the PDF does not resolve the exact boundary convention. Silently replacing 224 by 227 would change the source record.

The Figure 2 caption gives 253,440 first layer neurons. That does not equal the product of its drawn 55 × 55 × 96 shape. The abstract’s approximately 650,000 neurons is consequently a scale description here. It is not treated as a fully reconciled exact sum. The subsequent arithmetic states its shape assumptions explicitly.

A local operator with shared weights

z[o,u,v] = b[o] + Σ_(c∈G(o)) Σ_a Σ_b W[o,c,a,b] x[c,Su+a−P,Sv+b−P]

The input channel set G(o) depends on the output group. A spatial location changes which input patch is read. It does not select a different kernel. This distinction explains why the same layer can have relatively few parameters while applying those parameters many times.

Fitting speed and local competition

ReLU changes a local derivative

ReLU(z) = max(0,z); d ReLU(z)/dz = 1 for z > 0, and 0 for z < 0; d tanh(z)/dz = 1 − tanh²(z)

A positive ReLU has derivative one. A tanh unit has a small derivative when its magnitude is near saturation. This local mechanism can make gradient based fitting faster. It does not prevent a negative ReLU from receiving zero local sensitivity. It also does not by itself prove a test error improvement. The paper separates faster fitting from regularization.

Response normalization acts across channels

bᵢ_(x,y) = aᵢ_(x,y) / (k + α Σ_(j=max(0,i−⌊n/2⌋))^(min(N−1,i+⌊n/2⌋)) (aʲ_(x,y))²)^β; k = 2; n = 5; α = 10⁻⁴; β = 0.75

Here a is the activation after ReLU. The denominator combines neighboring channel maps at the same spatial location. Large nearby responses suppress the normalized response. The map order is arbitrary but fixed before learning. The source uses α times the sum, without division by n. A library implementation that instead scales by α/n needs a corresponding parameter conversion.

This operation follows convolutional layers 1 and 2. It does not subtract a local mean. It is therefore different from mean centered contrast normalization and from normalization over a minibatch. Its relevance is empirical in this architecture. The paper reports improvements, rather than a general requirement for every ReLU network.

Pooling changes which local responses survive

p[c,u,v] = max_(0≤a<3, 0≤b<3) h[c,2u+a,2v+b]

The network uses a pooling window of 3 × 3 with stride 2. Adjacent windows overlap. The comparison uses a 2 × 2 window with stride 2 and equivalent output dimensions in the authors’ setup. The reported benefit concerns this comparison. Pooling can discard exact position information, so it does not produce cost free invariance.

Data augmentation: the invariances are chosen

Preprocessing establishes a fixed input

The shorter side of each image is resized to 256 pixels. A central 256 × 256 region is then retained. The training set mean is subtracted from pixel values. The network receives RGB values rather than a handcrafted feature descriptor. This pipeline still makes a spatial selection before the learned model sees the image.

A crop is an observation, not a new independent image

Training draws random 224 × 224 patches and applies horizontal reflection. The authors describe a 2,048 fold expansion in possible training views. These views share an original photograph and label, so their statistical information is strongly dependent. The number does not establish 2,048 times as many independent examples.

The intended assumption is that modest translation and horizontal reflection usually preserve the category. This is an approximation about the selected dataset. A crop can remove an object, and a transformation can alter meaning in another task. The augmentation policy is consequently part of the learning problem.

Prediction averages ten probabilities

p̄(c|x) = (1/10) Σ_(t=1)^10 pθ(c|T_t(x))

The test views are the four corners and center, together with their reflections. The network averages softmax probabilities across these ten patches. This is additional inference computation. It is not a ten model parameter ensemble, and it is not an average of logits before softmax.

PCA perturbation acts on the image as a whole

ΔI = [p₁,p₂,p₃] [α₁λ₁, α₂λ₂, α₃λ₃]ᵀ; α_i ∼ Normal(0,0.1²); I′_(x,y) = I_(x,y) + ΔI

The vectors p and values λ are eigenvectors and eigenvalues of the RGB pixel covariance over the training set. Each α is sampled once per image presentation and shared by every pixel in that image. It is resampled when that image is used again. The PDF multiplies by λ, not its square root.

This low dimensional perturbation approximates changes in illumination intensity and color. It differs from independent pixel noise because the same RGB shift is applied everywhere. Section 4.1 reports a top 1 error reduction of more than one percentage point. The augmentation runs on the CPU while the GPU processes the preceding batch, which hides much of its cost in this implementation.

Optimization and dropout: what actually changes

The objective rewards the correct label

pθ(c|x) = exp(z_c)/Σ_(j=1)^1000 exp(z_j); L_B(θ) = −(1/|B|) Σ_(i∈B) log pθ(y_i|x_i)

Section 3.5 maximizes the average log probability of the correct label. Minimizing the negative form above is equivalent. The class labels supply supervision to all learned layers through backpropagation. A lower training objective alone does not establish lower held out error, which is why the regularization and evaluation details matter.

The original dropout convention

m_j ∼ Bernoulli(0.5); h̃_j = m_j h_j during training; h̃_j = 0.5 h_j at test time

Dropout is applied to the first two fully connected layers. Each presentation samples a mask and shares the underlying weights with all other masks. Dropped activations contribute neither their forward values nor their local backward path. This discourages reliance on one fixed set of companion features. It does not train each sampled subnetwork independently.

At test time the paper retains all units and multiplies their outputs by 0.5. Many later implementations instead divide surviving activations by the keep probability during training and use no test scaling. Mixing these conventions changes the computation. The paper calls deterministic test scaling an approximation to model combination, rather than an exact identity for this nonlinear network.

The authors report substantial overfitting without dropout. They also report roughly twice as many iterations to convergence with it. This exchanges additional optimization work for better generalization in their setting. It is separate from averaging several fully trained CNNs at competition time.

SGD includes coupled weight decay

g_i = (1/|D_i|) Σ_(x,y∈D_i) ∂ℓ(x,y;w_i)/∂w; v_(i+1) = 0.9v_i − 0.0005εw_i − εg_i; w_(i+1) = w_i + v_(i+1)

The batch contains 128 examples. Momentum is 0.9 and weight decay is 0.0005. The decay term enters the velocity update with the learning rate ε. It is not a statement about a modern decoupled decay optimizer. The authors also observe lower training error from this small decay, so its reported effect is broader than suppressing a train to test gap.

The storage estimate assumes four bytes per parameter and uses decimal megabytes. Gradients, momentum, activations and temporary buffers add storage. The actual hardware report

Section 5 reports about five to six days on two NVIDIA GTX 580 GPUs with 3 GB each. That is roughly ten to twelve GPU days for one training run. It is not the total research cost of architecture selection, failed runs, pretraining and ensembles. The paper does not provide enough timings to reconstruct those totals or the exact inference cost of every competition entry.

The main constraint is a coupled one. A larger network needs storage and time, while regularization can require more iterations. A second GPU can permit a different model, rather than merely execute the same model faster. Resource accounting therefore needs a fixed model and stopping rule before it supports a clean speed comparison.

Interpretation: what the paper establishes

The change is in learned features and feasible scale

The comparison to SIFT plus Fisher vectors changes the representation pipeline. A supervised objective now adjusts the image feature extractor together with the classifier. Earlier convolutional networks already supplied locality and sharing. This paper combines those ideas with a scale of labelled data, computation and regularization that produces a large competition improvement. The source does not support attributing the whole result to inventing convolution or ReLU here.

Depth has evidence, but the mechanism is not isolated

Removing a middle convolutional layer worsens top 1 performance by about two percentage points in the authors’ report. This supports the usefulness of the tested depth. It does not provide a matched comparison that holds receptive fields, optimization, connectivity and computation fixed. The removal changes several properties at once.

Questions that follow from the evidence

A modern replication could separate capacity from communication by fixing parameter count, model connections and training budget. It could compare activation choices at equal validation quality and measure both examples processed and elapsed time. These are proposed tests motivated by the confounds above. They are not experiments performed in this note.

The durable argument is that representation learning becomes effective when statistical assumptions, optimization, regularization and computation fit the task together. The numerical evidence is specific to the reported datasets and protocols. The paper’s expectations about unsupervised learning and video are future directions in its 2012 discussion, rather than outcomes established by these tables. The author code link points to the archived historical project. This reading did not execute that code or verify a complete working environment.
